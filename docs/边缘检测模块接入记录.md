## 二、ICF 链接脚本变更详情

文件: `project/iar/icf/linker_directives_tviibh.icf`

### 变更 1: TCM 段 copy 初始化

```icf
// 在 initialize by copy { readwrite }; 之后新增:
initialize by copy { ro section .itcm_text, rw section .dtcm_data };
```

启动时将 `.itcm_text` (热点函数) 从 Flash 拷贝到 ITCM，将 `.dtcm_data` (有初值数据) 拷贝到 DTCM。

### 变更 2: DTCM BSS 不自动初始化

```icf
// 在 do not initialize { section .intvec_ram }; 之后新增:
do not initialize { section .dtcm_bss };
```

DTCM 上电随机值，由 ECC 初始化 + 用户代码处理清零。

### 变更 3: TCM 段放置指令

```icf
// 在 place at end of SRAM { block HEAP_STACK }; 之后新增:
place in SELF_ITCM { rw section .itcm_text };
place in SELF_DTCM { rw section .dtcm_data, section .dtcm_bss };
```

将 ITCM/DTCM 段分别放到核内 0 等待内存区。

## 四、核心 API (极简封装)

对外仅暴露两个函数和一个输出结构体，模块完全自包含。

### 4.1 初始化

```c
#include "vision_edge_detect.h"

EdgeDetect_Init();  // 清零 DTCM 缓冲和内部状态
```

### 4.2 处理一帧 → 判定颠簸路段

```c
edge_detect_output_t result;

// camera_buffer: uint8[120][188] 灰度图像 (摄像头 DMA 目标地址)
EdgeDetect_Process((const uint8_t *)camera_buffer, &result);

if (result.is_bumpy) {
    // 在颠簸路段! R² > 0.8
    // result.dir_x, result.dir_y: 归一化方向向量
    //   用于导航: 方向向量指向边缘主方向, 可映射为转向指令
}
```

耗时参考: ~8.2ms @125MHz, ~4.1ms @250MHz

### 4.3 输出结构体

```c
typedef struct {
    uint8  is_bumpy;    // 是否在颠簸路段 (R² > 0.8)
    float  dir_x;       // 方向向量 X 分量 (归一化, [-1, 1])
    float  dir_y;       // 方向向量 Y 分量 (归一化, [-1, 1])
} edge_detect_output_t;
```

- `is_bumpy`: 强边缘方向一致性 R² > 0.8 时判定为颠簸路段
- `dir_x, dir_y`: 归一化方向向量 = (ΣGx, ΣGy) / |(ΣGx, ΣGy)|
  - 指向图像中强边缘的主方向
  - 直行时 ≈ (±1, 0)，转弯时向量旋转

```c
// 在 vision 主循环中 (例如 vision_ipc_core1 的处理函数中):
#if VISION_EDGE_DETECT_ENABLE
    if (/* 颠簸路段模式启用 */) {
        VisionEdgeDetect_ProcessFrame(camera_image_ptr);

        const volatile vision_edge_detect_result_t *edge_res =
            VisionEdgeDetect_GetResult();

        if (edge_res->valid) {
            // 将结果填入 IPC bumpy 字段

            g_vision_ipc_result.bumpy_steer_error_px_x100 = edge_res->steer_error_px_x100;
            g_vision_ipc_result.bumpy_confidence_u16      = (uint16)(edge_res->r_squared * 1000.0f);
            // ... 填充其他 bumpy 字段 ...
        }
    }
#endif
```

## 十、已知限制

1. **图像尺寸固定**: 当前仅支持 188×120 输入，不同于 bumpy_vision 使用的 94×60
2. **阈值需标定**: `EDGE_FIXED_THR_DEFAULT=1500` 为参考值，需根据实际场景用标定脚本重算
3. **角度→转向映射**: `EDGE_ANGLE_TO_STEER_GAIN` 为线性近似，实际可能需要非线性校准
4. **中断安全**: 处理期间 ISR 不得写入 DTCM 环形缓冲
5. **ICF 纯 ASCII**: ICF 文件中 TCM 段注释必须使用英文，中文注释可能导致链接器跳过后续行
