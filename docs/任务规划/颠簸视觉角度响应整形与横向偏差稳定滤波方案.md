## 0. 背景与角色边界

### 0.1 三个问题的现状证据（源码核实）

**问题 A：角度"测出来但进不了控制"——阈值门控把视觉修正永久掐断**

1 核侧角度已与边线解耦（**夹角基于横向连通域，与边线成败无关**）：

- `bumpy_pipeline.c:585-588`：`frame_heading()` 对**全部横向线性连通域**方向角做加权圆均值（权重=像素数），输出条纹航向角 `hdg`；边线 L/R 的 `valid` 由 RANSAC + 时间验证决定，与 `hdg` 无关。
- `bumpy_vision.c:407-417`：`yaw_error_deg_x100` **永远取 `hdg`**；`meas_valid = hdg_valid`。边线跳**不影响角度**。

0 核接入被二进制门控卡死：

- `vision_bumpy_control.h:38`：`VISION_BUMPY_HEADING_STABLE_TOL_DEG = 1.0°`，`vision_bumpy_control.c:322-339` 要求**相邻帧角度差 ≤1° 连续 3 帧**才置 `heading_stable`。
- `bumpy_road.c:106-136` `ApplyYawHold()`：**只有 `heading_stable==1`** 才用 `err_degree_cmd`，否则锁入口/失稳前航向。

颠簸路上 100fps 帧间角度抖 2~5° → 门控反复清零 → `heading_stable` 恒 0 → **视觉角度永远到不了方向盘**。

**问题 B：`yaw_error==0` 时回退分支是 -90° 硬转向 bug**

- `vision_bumpy_control.c:61-69`：`yaw_error_deg_x100 == 0` 时回退 `-atan2f(direction_x, direction_y)`。
- 新管线 `direction_x/y = (cos hdg, sin hdg)`（条纹方向），回退公式假设的是**旧算法**的"行驶/法向方向"约定。
- 后果：车精确对准（`hdg=0`）且 `meas_valid=1` → `-atan2f(1,0) = -90°` → 限幅成 `-18°` 硬转向。

**问题 C：横向偏差"测了但没修惯导"**

- `vision_bumpy_control.c:311-320`：`recorded_lateral_mm` = EMA(α=0.5，仅 `lateral_mm≠0` 更新)——**只记录**。
- `bumpy_road.c:384-390`：唯一消费点，出口确认后把 `nav_vision_fusion` 钉到出口锚点并**一次性**叠加 `recorded_lateral_mm`（段内全程 EMA 的平均语义）。
- 颠簸段全程 `nav_vision_fusion` 是纯惯导推算（`inertial_nav.c:149-150`）：打滑/冲击导致的横向积分漂移**段内无人修正**；出段前位置早已不准，且出口叠加量是"全程平均"而非"脱出时刻的真实偏差"，锚点链任一环断（`entry_confirmed`→`visual_exit_armed`→`exit_confirmed`）即不叠加。

### 0.2 角色边界（v2 定案，v3 维持）

| 层 | 模块 | 职责 | 边界 |
|---|---|---|---|
| 视觉提案层 | `vision_bumpy_control.c` | 把视觉观测转成**提案**：`yaw_error → 整形 → 自适应EMA → err_degree_cmd`；lateral 稳定滤波产出 `lat_stable` | **不做 PID、不写 `err_degree`、不碰 `nav_vision_fusion`** |
| 转向仲裁层 | `bumpy_road.c` | **`err_degree` 的唯一写入者**：按任务状态决定用视觉提案（直接接入）/ 锁航向 / 置 0 | 仲裁权不旁落；**不二次平滑提案** |
| 惯导修复层 | `bumpy_road.c`（同文件，独立函数） | 在**脱出状态机确认时刻**，用 `lat_stable` **一次性**修正 `nav_vision_fusion` | 只修位置一次，不叠加转向，段内不做 |

### 0.3 总体设计原则（v3）

1. **角度与横向解耦**：角度走"条纹角（连通域直出）"路径，横向走"边线 + IPM"路径，滤波独立。
2. **视觉侧零 PID**：`err_degree_cmd` 由整形+EMA 直接产出（整形本身即非线性 P 控制器），不实现也不调用 `vision_bumpy_pid_calc`；PID 参数宏删除。
3. **`err_degree` 仲裁权归控制侧**：视觉侧永远只写自己的 `err_degree_cmd` / `g_vision_bumpy_control_status`，`err_degree` 由 `bumpy_road` 独家写入；**自适应滤波已足够，提案直接接入，无仲裁层二次平滑**。
4. **lateral 只修惯导，不对中，且一次性**：稳定滤波输出仅用于**脱出时刻一次性**修正 `nav_vision_fusion`（+ 出口兜底），不进转向闭环、段内不修正。
5. **valid 语义不变**：`meas_valid` 仍只标记"条纹也没有"的严重丢失；边线可信度用"lateral 本身是否为 0 + 滤波状态机"表达，**不新增 IPC valid 位**。
6. **IPC 契约冻结**：字段、位数、打包逻辑不动。

## 1. 方向一：角度响应整形滤波器（近高远低 + 自适应阻尼，零 PID，无二次平滑）

### 1.1 设计目标（用户语义）

- 已对准（小角度）：**高响应、灵敏**；偏离大（大角度）：**低响应、有阻尼**；
- 抖动被滤波器连续吸收，不再被二进制门控"清零重数"；
- 视觉侧**不实现 PID**：整形+EMA 直接产出 `err_degree_cmd`；
- **`err_degree_cmd` 不再二次平滑**——自适应滤波已经是唯一平滑环节，`bumpy_road` 直接接入。

### 1.2 算法结构

```
raw[n] = yaw_error_deg_x100 × 0.01 × VISION_BUMPY_YAW_SIGN   // 有观测
raw[n] = 0（锁当前角度）                                      // meas_valid=0（§2 语义）

① 静态整形（近高远低）：
   shaped[n] = raw[n] / (1 + B·|raw[n]|)

② 角度自适应时间滤波：
   α[n] = ALPHA_MAX · exp(−|raw[n]| / τ0)
   err_f[n] = α[n]·shaped[n] + (1 − α[n])·err_f[n−1]

③ 死区/限幅：
   err_degree_cmd = clamp(err_f[n], ±MAX_ERR_DEG)；|err_f| < DEADBAND → 0
```

初值（100fps，待整定）：`B = 0.06 /°`、`ALPHA_MAX = 0.40`、`τ0 = 3.0°`、`MAX_ERR_DEG = 18°`、`DEADBAND = 0.2°`（见 §6.1）。

**无 PID、无二次平滑的说明**：整形 `S(e)=e/(1+B|e|)` 本身就是非线性比例控制器（增益随 |e| 自动衰减），EMA 处理噪声；二者级联即是"提案"的全过程。不引入积分（I）——颠簸段抖动主导，积分在观测间歇期易累积虚假，且静差不影响任务目标（见 §1.3.2 数值）；不引入微分（D）——D 对抖动量放大。`err_degree_cmd` 即最终提案值，`bumpy_road` 仲裁后**直接写入 `err_degree`**，不再加任何 EMA/限幅（现状 `BUMPY_ROAD_STEER_FILTER_ALPHA` 的二级平滑删除，见 §5.2）。

### 1.3 数学证明

#### 1.3.1 整形函数性质

定义 `S(e) = e/(1 + B|e|)`，`B > 0`，`e ∈ ℝ`。

**性质 1（奇函数）**：`S(−e) = −S(e)` —— 左右对称，符号语义（正=需右转）不破坏。

**性质 2（严格单调）**：`dS/de = 1/(1+Be)² > 0`（e>0），e<0 对称同理。严格递增 → 输出与输入同号单调，不产生符号反转。

**性质 3（局部增益 = 近高远低）**：

```
g(e) = dS/de = 1/(1 + B|e|)²
```

- `|e|→0`：`g→1`（线性灵敏度，小角度跟手）；
- `|e|→∞`：`g→0`（大角度阻尼）；
- `B` 只压缩幅度，不反转方向。

**性质 4（有界输出，天然限幅）**：`|S(e)| < 1/B`，`lim_{|e|→∞} = 1/B`。**`1/B` 即等效输出限幅**。取 `MAX_ERR_DEG=18°`、`B=1/18≈0.056` 得与硬限幅相同上界，但整形是**连续饱和**（smooth saturation），无硬限幅角点。

**性质 5（小角度线性近似）**：`|e| ≪ 1/B` 时 `S(e) = e − B·e·|e| + O(B²e³)` ——"先线性，再随偏差二次项压缩"。

#### 1.3.2 闭环收敛性（比例型控制，K 为级联等效增益）

转向误差动态取一阶模型（方向闭环带宽内有效）：`ė(t) = u(t) + d(t)`。采用比例整形控制 `u = −K·S(e)`（`K>0` 为 `err_degree → 转向角 → 航向` 的级联等效增益，由控制侧执行链决定，与视觉提案层实现无关）。

**无扰动（d=0）渐近稳定**：取 `V = ½e²`，`V' = e·ė = −K·e²/(1+B|e|) ≤ 0`，等号仅 e=0；由 LaSalle 不变集原理 `e→0`。

**收敛速率自适应（核心性质）**：误差动态 `ė = −λ(e)·e`，`λ(e) = K/(1+B|e|)`：

- `|e|` 大 → `λ` 小 → 收敛慢、阻尼大（等效时间常数 `τ(e)=1/λ(e)=(1+B|e|)/K` 大）；
- `|e|→0` → `λ→K` → 收敛快、灵敏（时间常数 `τ(0)=1/K`）。

**阻尼放大倍数** `τ(e)/τ(0) = 1 + B|e|`：`B=0.06` 时 `|e|=3°→1.18×`、`|e|=12°→1.72×`、`|e|=20°→2.2×`。大偏差慢、小偏差快——"大角度有阻尼、小角度灵敏"。

**恒扰动静差（数值小，接受不处理）**：`d≡d₀` 时平衡点 `|e*| = (|d₀|/K)/(1 − B|d₀|/K)`（需 `B|d₀|/K<1`），相对线性 P 的 `|d₀|/K` 略增大；`B=0.06`、`|d₀|/K=1°` → 静差 1.064°。颠簸任务不要求精确对准（不考核直线度指标），且静差为有界小量，**不做任何消静差机制**（v3 删除 v2 的 §1.5 控制侧慢积分变体）。

#### 1.3.3 时间滤波（自适应 EMA）性质

```
x[n] = S(raw[n]);  α[n] = ALPHA_MAX·exp(−|raw[n]|/τ0) ∈ (0, ALPHA_MAX] ⊆ (0,1]
err_f[n] = α[n]·x[n] + (1−α[n])·err_f[n−1]
```

**(a) BIBO 稳定**：固定 α 时 `H(z) = α/(1−(1−α)z⁻¹)` 极点 `z_p = 1−α ∈ (0,1)` 在单位圆内 → 渐近稳定无振荡；α 时变时各帧极点仍在 (0,1) 内连续变化（每帧压缩 `1−α[n] ≤ 1−ALPHA_MIN < 1`）→ 稳定。

**(b) 阶跃跟手度**：输入阶跃 X，`err_f[n] = X·(1−(1−α)ⁿ)`；上升到 1−δ 需 `n_rise = ln δ / ln(1−α)` 帧：

| α | n_rise(δ=0.05) | 语义 |
|---|---|---|
| 0.40（小角度） | ≈6 帧（60ms） | 跟手 |
| 0.15（大角度） | ≈18 帧（180ms） | 阻尼 |

**(c) 单帧野值抑制（对比门控清零）**：脉冲 δ 注入 → 输出尖峰 `Δout ≤ ALPHA_MAX·|δ| ≤ 0.4|δ|`，随后指数衰减。现状三帧门控：任一跳帧即整段指令切"锁航向"。**滤波不中断，只衰减扰动**。

**(d) 抖动脉动方差压缩**：白噪声方差 σ² 输入，AR(1) 稳态输出方差 `Var = σ²·α/(2−α)`：`α=0.4→0.25`（−6dB）；`α=0.15→0.081`（−11dB）。大角度抖动额外压 5dB+。

**(e) 门控 vs 滤波的数学本质**：三帧门控 = 假设检验，高斯抖动 σ=1.5° 下单帧通过率 `P(|ν|<1°)=erf(1/(1.5√2))≈0.49`，连续 3 帧 ≈0.12 → 抖动敏感易断；自适应 EMA = 白噪声下最小方差线性估计，**无条件持续输出**。

**(f) 无需二次平滑**：自适应 EMA 已按 |raw| 调制平滑强度（小角度 α 大→快、大角度 α 小→慢），`err_degree_cmd` 序列自身即满足"连续、平滑、跟手"三性。再叠加固定 α 的仲裁层 EMA（现状 `BUMPY_ROAD_STEER_FILTER_ALPHA=0.05`）会：
   - 给大角度/小角度**统一**再加延迟 `n_rise ≈ ln0.05/ln0.95 ≈ 58 帧（580ms）`——破坏"近高远低"的快速响应设计；
   - 两级 EMA 串联等效一阶双极点，相位裕度额外损失，颠簸场景易诱发放大扭动。
   故 v3 删除该二次平滑，`err_degree = err_degree_cmd` 直接接入。

#### 1.3.4 稳定性结论汇总

| 层面 | 结论 | 依据 |
|---|---|---|
| 整形 | 单调、有界、符号保持、增益近高远低 | 性质 1~5 |
| 闭环（无扰动） | 渐近稳定，收敛速率自适应 | V=½e² 李雅普诺夫 |
| 闭环（恒扰动） | 静差有界（1.064×线性 P），接受不处理 | §1.3.2 |
| 时间滤波 | BIBO 稳定、野值 ≤0.4δ、抖动 −6~−11dB | §1.3.3 |
| 接入链 | 提案 → `err_degree` 直接写入，无二次平滑 | §1.3.3(f) |

### 1.4 接入：`err_degree_cmd` 是提案，`err_degree` 由 `bumpy_road` 独家写入且不二次平滑

```
vision_bumpy_control（视觉提案层，零 PID）
  yaw_error → 整形 → 自适应EMA → err_degree_cmd   ← 只写自己的状态

bumpy_road.ApplyYawHold（转向仲裁层，err_degree 唯一写入者）
  视觉可信（meas_valid=1，含 HOLD 透传，§3）:
      err_degree = err_degree_cmd                  // 直接接入，无二次平滑
  失稳（meas_valid=0）:
      err_degree = NormalizeAngle(held_yaw − yaw)  // 锁失稳前/入口航向（现状保留）
  出口修正后:
      err_degree = 0
```

- `heading_stable` 三帧门控**删除**；角度抖动由 §1.3.3 滤波器吸收；
- `BUMPY_ROAD_STEER_FILTER_ALPHA`、`s_bumpy_ctx.filtered_err_degree` **删除**（二级平滑取消）；
- 全局 `err_degree` 是控制侧专用（转向角度环消费），视觉模块任何路径都不直接写它。

## 2. 方向二：修复 `yaw_error==0` 回退 bug（锁当前角度）

### 2.1 触发场景（精确）

| 条件 | 现状行为 | 后果 |
|---|---|---|
| `yaw_error_deg_x100 == 0` 且 `meas_valid==1`（hdg=0，车精确对准） | 走回退 `-atan2f(1,0) = -90°` | 限幅 −18° 硬转向 |
| `meas_valid==0`（无线无条纹） | 0 核走失稳分支，不经回退 | 无影响 |

### 2.2 修复语义（用户确认）

**`yaw_error==0` → `err = 0.0f`（锁当前角度，不给新指令）**。删除 `-atan2f(direction_x, direction_y)` 回退分支；`direction_x/y` 降级为纯遥测字段。

### 2.3 验证

1. 车精确对准（`hdg≈0`）100 帧 → `err_degree_cmd ≡ 0`，无 −18° 尖峰；
2. 偏右 5° → `err_degree_cmd ≈ 5/(1+0.06·5) = 3.85°`（整形后，对照 §6.1 表）；
3. 旧管线回退：`BUMPY_USE_NEW_PIPELINE=0`，`is_bumpy=0` 时角度 0 且 `meas_valid=0`，行为不变。

## 3. 方向三：lateral 稳定滤波（满窗中值 + 门控 + 保持状态机，出口一次性修惯导）

### 3.1 设计目标（用户语义）

"基于连续滤波之后的数据，再结合门控通过，去做一个数据稳定滤波器"：
- **先中值去野值，再门控放行，最后状态机输出稳定值**；
- **中值窗口必须满 3 个可检测帧（lateral_raw≠0）才输出**——窗口只装有效观测，0 帧不凑数，不满窗不输出（状态机保持）；3 帧中值即替代原 `heading_stable`"连续 3 帧"的时序稳定性职责，但改为中值语义（野值剔除 + 无偏性，§3.3）而非假设检验（一帧跳变即清零）；
- 边线跳变期间保持（不归零），出路段才冻结。

**用途（v2/v3 定案）**：`lat_stable` **仅用于惯导 `nav_vision_fusion` 的修正**，且**只在脱出状态机确认时刻一次性修正**（v3）——不参与转向对中、段内不做任何位置修正。状态机不追求"车居中于条纹"，只追求"脱出时刻能给出一个经过稳定滤波的、可信的横向偏移，一次性补偿颠簸段内惯导积分漂移"。

### 3.2 算法结构（1 核适配层，新增滤波状态，IPC 不变）

```
每帧输入 lateral_raw（0 = 本帧无横向观测：单侧无/间距自检失败）

① 中值预滤波（满窗非零门控，N=3）：
   有效帧序列 w_j（按时间序，lateral_raw≠0 且非野值的帧）
   仅当累计有效帧 ≥3：W = {w_{j-2}, w_{j-1}, w_j}，x_mid = median(W)
   不足 3 帧：无输出（状态机保持，lat_stable 不更新）
   单帧 |Δx| > J 视为野值 → 该帧不入窗，直接进 HOLD

② 门控 C（三者同时满足才允许更新）：
   C1 观测存在（lateral_raw ≠ 0）
   C2 边线时间验证通过（管线 hist_update 连续 3 帧稳定）
   C3 间距自检通过（双侧 |(x_R−x_L)−1000| ≤ 150mm；单侧视为通过）

③ 状态机（丢失计数 miss）：
   LOCK  : C=1 且满窗 → x_f = (1−β)·x_f + β·x_mid，miss=0
   HOLD  : C=0 或未满窗，且 miss ≤ K → x_f 保持，meas_valid 保持 1，miss++
   FREEZE: miss > K → 冻结 x_f，meas_valid=0
```

输出：`lat_stable = x_f`（int16 mm，车身偏右为正）。初值（100fps）：`N=5`、`J=80mm`、`β=0.30`、`K=5`（§6.2）。

> **满窗语义强调**：`W` 的 5 个元素必须全部来自**可检测帧**（`lateral_raw≠0` 且非野值）。边线闪烁时有效帧可能隔帧到达，累积满 5 个有效帧所需真实时间可能 >50ms；不满窗期间 `lat_stable` 保持（HOLD），**宁可慢、不可错**。

### 3.3 数学证明

#### 3.3.1 观测模型

```
z[n] = x_true[n]·m[n] + η[n]
```

`x_true` 真实横向偏移；`m[n]∈{0,1}` 观测存在标志；`η` 含重尾/野值噪声（颠簸、遮挡、误检经 IPM 放大）。

#### 3.3.2 中值预滤波（满窗）

有效样本序列 `w_1, w_2, …`（lateral_raw≠0 且非野值），仅当 j≥5 时 `x_mid = median(w_{j-4..j})`。

**(a) 崩溃点 50%**：≤⌊(N−1)/2⌋ = 1 个野值对中值**零影响**（任意大、任意符号）；均值崩溃点 0%。N=3 时每窗容忍 1 个野值，相对均值（0 容忍）仍是数量级改善。**前提是窗口满员**——这就是"必须满 3 个可检测帧"的原因：不满窗时中值的崩溃点/方差性质不成立，此时宁可不输出（HOLD），也不放行一个统计意义缺失的估计。

**(b) 有界**：`min W ≤ x_mid ≤ max W`，天然抗 IPM 饱和/离群。

**(c) 高斯噪声效率**：渐近 `Var(median) = 1/(4·N·f(m₀)²)`，高斯 σ 下 ≈ `(π/2)·σ²/N`（均值 `σ²/N`，效率 1.57 略劣）；重尾/野值下远优。颠簸噪声重尾 → 中值正确。

**(d) 阶跃响应（满窗延迟）**：输入从 0 跳到 X，需**累计 3 个有效样本**才首次输出 X（`t_delay = 3 有效帧`；有效帧连续时 30ms@100fps，边线闪时更长）。对**出口一次性修正**（秒级时间尺度）无影响；3 帧满窗在保证 (a)(c) 性质成立的前提下把时序延迟压到最小（等效替代原"连续 3 帧"门控的 30ms 量级时序窗口）。

**(e) 非零门控窗的偏置消除**：把 `m=0` 帧的 0 直接喂滤波器 → 稳态偏置 `bias = (1−m̄)·(−x̄_true)`（`m̄` 观测占空比）。40% 帧无观测 + 真实偏 100mm → **−40mm 恒定负偏置**。满窗非零门控从源头剔除这些帧 → 无偏置。此结论同时印证了现行 0 核"非零门控"（`vision_bumpy_control.c:311`）的正确性，并把它前移加强到 1 核。

**(f) 安全降级**：若段内累计有效帧始终 <3（条纹全程闪烁/误检），`lat_stable` 保持 0 → 出口修正量 0（无修正），**安全侧**——绝不把不可信估计写进位置。

#### 3.3.3 门控保无偏性

门控权重 `w[n] = 1{C1}·1{C2}·1{C3}`。门控下 `E[w·(z−x_true)] = w·E[η] = 0`（无偏）；未门控的 0 帧注入 `E[0−x_true] = −x_true ≠ 0`（有偏）。C2 剔除"边线拟合不可信"帧（噪声远超 IPM 精度），C3 剔除"间距异常=误检"帧——**门控 = 只允许可解释观测更新，保估计无偏**。

#### 3.3.4 HOLD 漂移上界

```
v_lat ≤ v·sin θ_max；v=0.8m/s（颠簸段速），θ_max=30°/s → v_lat ≤ 0.4m/s
K=5 帧 @100fps → 冻结期真实横向漂移 ≤ v_lat·50ms = 20mm
```

对比横向精度目标 ±50mm：**HOLD 5 帧保持误差 ≤20mm 可忽略**，且避免"边线恢复瞬间 0→真值跳变"。

#### 3.3.5 稳态误差上界（LOCK 满窗）

```
|lat_stable − x_true| ≤ σ_mid + v_lat·T/β + ε_IPM
```

- `σ_mid`：中值残余（高斯下 ≈1.25σ/√3 ≈ 0.72σ）；
- `v_lat·T/β`：EMA 滞后（β=0.3、T=10ms → ≈13mm）；
- `ε_IPM`：IPM 表量化。

初值组合量级 ≈ 30~50mm，落在静态精度目标 ±50mm 内。**这是出口一次性修正的输入精度上界**——即修正后 `nav_vision_fusion` 横向误差被压到该量级（相对不修的正常漂移，改善显著）。

### 3.4 惯导修正机制（脱出时刻一次性修正，v3 定案）

**放弃段内每帧增量修正，改为出口一次性**。理由：
- 位置估计只在"出段后重新导航"需要准确，段内修正收益小、复杂度高（增量基准、双重计数、SIGN 符号不确定时越修越偏）；
- 一次性修正把风险收敛到一个时刻、一个量：**可标定、可验证、可回退**。

```
脱出状态机确认（exit_confirmed 置位）瞬间执行一次：
  lat_exit = lat_stable                       // 稳定滤波值：HOLD 保持 / FREEZE 冻结的最近可信值
  θ = inertial_nav.relative_yaw (rad)
  nav_vision_fusion_x += SIGN · lat_exit · sin θ
  nav_vision_fusion_y −= SIGN · lat_exit · cos θ
  此后不再做任何横向位置修正（段内/段后均不）
```

**语义**：脱出瞬间车相对条纹中线的横向偏移（满窗稳定滤波值）≈ 颠簸段内惯导横向漂移的最终度量。`lat_exit` 在脱出时刻读取：此时边线已连续 3 帧丢失（`exit_confirmed` 判定条件），`lat_stable` 正处于 HOLD 保持（≤K 帧）或 FREEZE 冻结状态，取到的正是**最后一次满窗 LOCK 的可信值**。

**与现状的差异**（`bumpy_road.c:384-390`）：
- 现状：`recorded_lateral_mm` = 段内全程 EMA（**平均语义**），出口叠加；
- 本方案：`lat_exit` = **脱出时刻的瞬时稳定值**（满窗中值 + 门控 + EMA + 保持的最终输出），更贴近"出段时刻的真实偏差"。
- 保留：出口锚点钉住流程（`exit_anchor_valid` 时先钉锚点再叠加 `lat_exit`）、`BUMPY_LATERAL_OVERLAY_SIGN` 符号开关（实车标定）。

**修正精度论证**：
- 修正误差 = 视觉稳态误差（§3.3.5 ≤30~50mm）+ 投影符号误差（SIGN 标定后为 0）+ 出段后惯导重新积分（平地，积分误差小）；
- 对比现状：出口叠加量是全程平均（对"出段时刻真实偏差"有统计偏差），且锚点链任一环断即完全无修正；本方案修正量来源更准、环节不变。

### 3.5 与对中 / 段内修正的明确区分

| | 对中（不采用） | 段内增量修正（不采用） | 出口一次性修正（本方案） |
|---|---|---|---|
| 用途 | 用 lateral 修正转向让车居中 | 段内逐帧修位置 | 脱出时刻一次性修位置 |
| 作用对象 | `err_degree` | `nav_vision_fusion` | `nav_vision_fusion` |
| 时机 | 全程 | 段内每帧 | 出口确认瞬间一次 |
| 风险 | 过修正/振荡/条纹非赛道中心误导 | 双重计数、SIGN 不确定越修越偏、复杂度高 | 修正量时效性（取脱出时刻值，语义正确）；量可标定 |

1. 构建通过 + map 复核（0 核 −PID 结构 + 少量浮点；1 核 +滤波状态 ≤100B，rw data 余量 6,510B 内确认）；
2. 上位机遥测：`yaw_error_deg_x100 / lateral_mm / meas_valid` 全程连续性；
3. §6.4 六项符号/行为验证。

### 7.3 实车

1. 颠簸段连续实跑：`err_degree` 连续性（对比现状"恒锁航向"）；确认无二次平滑后响应跟手、无 580ms 级延迟；
2. **出口一次性修正**：颠簸段内人为右漂 → 脱出后 `nav_vision_fusion` 与真实轨迹误差（目标 ≤±100mm，对比现状无修正/平均量修正的漂移）；
3. 出口落点精度（目标 ≤±100mm）。

## 8. 风险与回退

| 风险 | 缓解 |
|---|---|
| 大角度阻尼过强 → 拉不回 | `B` 调小；实车大偏差专项测 |
| EMA 相位滞后 → 振荡 | 两级 α 解耦：先 `ALPHA_MAX` 再 `τ0`；无二次平滑后链路只剩一级滤波，风险更低 |
| 满窗延迟导致出口修正量时效差 | 满窗 3 有效帧 ≈30ms（连续有效时），对秒级出口尺度无影响；有效帧断续时 lat 保持 HOLD 值，仍为最近可信值 |
| HOLD 保持值失真 | K 取边线闪 p95；FREEZE 后锁航向兜底不变 |
| 出口修正方向错 → 位置越修越偏 | §6.4 静态验证前置；`SIGN` 开关保留 |
| 出口修正量 = 全程未满窗 → 0 | 安全侧降级（不修），不会写入错误位置；实车若频繁触发需检查边线检出率 |
| 条纹中线非赛道中心 → 位置系统偏 | 颠簸段为直道，近似成立；若实测系统偏，对 `lat_exit` 加静态标定偏移（文档待扩展，不在本方案范围） |
| 内存超限 | 新增状态 ≤100B 级；构建后 map 复核 |
| 回退 | `BUMPY_USE_NEW_PIPELINE=0` 一键回旧算法；0 核改动集中可独立提交 |

## 9. 附录：符号表

| 符号 | 含义 |
|---|---|
| `e / raw` | 视觉角度偏差（°），正=需右转 |
| `S(e)`, `g(e)` | 整形函数、瞬时增益 |
| `B` | 整形强度（/°） |
| `α`, `ALPHA_MAX`, `τ0` | 自适应 EMA 增益、上界、尺度（°） |
| `err_f`, `err_degree_cmd` | 角度滤波输出（°）、视觉提案值（**唯一平滑终点**） |
| `err_degree` | 全局转向接入变量，**bumpy_road 独家写入，直接取提案不二次平滑** |
| `z[n]`, `x_true`, `m[n]`, `η` | lateral 观测、真值、存在标志、噪声 |
| `w_j`, `x_mid`, `x_f / lat_stable`, `β` | 有效样本、满窗中值、稳定输出、LOCK EMA 系数 |

| `nav_vision_fusion` | 视觉+惯导位置估计（**lateral 唯一修正对象，出口一次性**） |
| `v_lat`, `θ_max` | 横向漂移速率、最大横摆角速度 |
