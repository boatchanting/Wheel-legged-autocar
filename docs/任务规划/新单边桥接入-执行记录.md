#### C26 卷积符号重命名（2026-08-08，编译隐患修复）
- **发现**：整理 trials/bridge 编译经验时，对照主工程发现 `code1/vision/edge_conv_asm.s`（bumpy_vision 在用）已导出 `conv1d_horiz_gxgy`/`conv1d_vert_gxgy_row`，与新拷贝的 `bridge_asm_ops.s` **重名** → 必然链接重复符号错误。
- **关键**：两实现虽 ABI 相同（r0-r3 + out_width），但**卷积核方向相反**——edge 的 S 核为 `[3,1,1,3]`（r6={3,1}/r11={1,3}），bridge 为 `[1,3,3,1]`（r6={1,3}/r11={3,1}）。梯度输出不同，模块阈值按 bridge 版本标定，**不可混用** → 不能简单删一方。
- **处理**：`bridge_asm_ops.s` 两个导出改名 `b2_conv1d_horiz_gxgy`/`b2_conv1d_vert_gxgy_row`（PUBLIC + 标签）；`bridge_asm_ops.h` 声明同步；`bridge_detect.c` 两处调用同步。`mlp_fc_s8_layer` 唯一无冲突不动。主工程 `edge_conv_asm.s`/`bumpy_vision.c` **零改动**。
- 验证：grep 确认模块侧无残留旧名；主工程侧 `conv1d_*` 仍只归 edge_conv_asm.s。
