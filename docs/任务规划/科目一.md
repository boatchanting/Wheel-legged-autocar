# 科目一的任务拆解
打点 ---> 存ram ---> 存flash ---> 读取flash ---> 解析flash ---> 放到ram ---> 根据ram里面的点来控制行驶

先写出nav_ram.h和nav_ram.c

## 惯导坐标系
利用遥控器打点，打几个点，打点由遥控器信号控制，这部分代码已有，无需实现，先存到ram，按下完成后存入flash
打点的记录存到flash里面格式为

索引头 惯导坐标点 总个数 plan种类
记录为
inertial_nav.x ，inertial_nav.y，点的类型由遥控器按键决定
0,0,0(初始点为0，0，类型是0号点)
13243.1321,121.2321,0(2号点为13243.1321，121.2321，类型是0号点)
11321.2231,121.2321,1(1号点为11321.2231，121.2321，类型是1号点，小车执行转圈任务)

存储结束标志，到最后一个点结束就行了

## 点的型号
plan可以由外部函数控制
### 在plan1中
0号点为路径点，即小车需要根据这个路径点来行驶
### 在plan2中
0号点为路径点，即小车需要根据这个路径点来行驶
1号点为转圈任务点，小车需要根据这个点来转2圈（给出标志位）
### 在plan3中
0号点为路径点，即小车需要根据这个路径点来行驶
1号点为上坡点，小车需要根据这个点来行驶上坡（给出标志位）
2号点为跳跃点，小车需要根据这个点来跳跃（给出标志位）
3号点为单边桥点，小车需要根据这个点来行驶单边桥（给出标志位）
4号点为草坪点，小车需要根据这个点来行驶双边桥（给出标志位）
5号点为颠簸路段点，小车需要根据这个点来行驶颠簸路段（给出标志位）

## 代码要求
1. 带结构化注释@brief @param @return @note
2. 不要使用结构体指针和结构体数组等复杂数据结构作为函数参数
3. 不要在函数中引入时间相关的参数，所有的时间都会在中断中进行控制
