# 0701GPS 架构与处理方式说明

本文档基于工程中实际实现的代码进行整理，剥离了所有尚未落实的理论与计划内容。下文涉及的所有功能均对应了实际的代码文件及具体的代码行数。

## 1. 硬件驱动与底层协议解析
GNSS 模块的底层驱动和解析主要集中在 `zf_device_gnss.c` 和 `zf_device_gnss.h` 两个文件中。

### 1.1 硬件配置与初始化
- **硬件支持类型**：代码支持 3 种逐飞科技的模块 `TAU1201`、`GN42A`、`GN43RFA`（`zf_device_gnss.h` : L83-L88）。
- **UART 引脚配置**：根据不同车模（`CAR_SELECT`），底层统一配置使用 `UART_2`（`zf_device_gnss.h` : L54-L77）。
- **初始化与配置**：在 `gnss_init()` 函数中，向非 RTK 模块发送多条指令，将刷新率设置为 10Hz，同时关闭不必要的 NMEA 语句（如 GLL、GSA、GSV 等），并开启串口接收中断（`zf_device_gnss.c` : L557-L617）。
- **串口中断接收**：`gnss_uart_callback()` 中断回调函数负责从 FIFO 中读取数据，并根据报头（RMC、GGA、THS）将数据分类拷贝到各自的缓冲区供主循环解析（`zf_device_gnss.c` : L485-L548）。

### 1.2 NMEA 协议解析
解析主函数 `gnss_data_parse()`（`zf_device_gnss.c` : L407-L481）首先进行异或校验，校验通过后调用相应的子函数将数据写入 `gnss_info_struct` 结构体：
- **RMC 解析**：`gps_gnrmc_parse()` 提取出经纬度、速度（转换为 km/h）、航向，以及时间（包含 UTC 转北京时间处理）（`zf_device_gnss.c` : L223-L284）。
- **GGA 解析**：`gps_gngga_parse()` 提取当前定位使用的卫星数量和海拔高度（`zf_device_gnss.c` : L287-L310）。
- **THS 解析**：`gps_gnths_parse()` 提取双天线定向状态和具体航向角（`zf_device_gnss.c` : L313-L340）。

### 1.3 基础几何测算
在 `zf_device_gnss.c` 中内置了基于地球半径（6378137m）的球面几何计算函数：
- `get_two_points_distance()`：计算两经纬度之间的直线距离（L343-L375）。
- `get_two_points_azimuth()`：计算从一点到另一点的方位角（L378-L398）。

## 2. 坐标转换层 (GNSS 到 平面笛卡尔)
在路径追踪时，球面坐标难以直接用于控制。项目将球面经纬度展平为局部二维平面坐标。
- **数据结构**：在 `gnss_transform.h` (L8-L28) 中定义了 `gnss_transform_struct`。
- **作用**：以上电初始化时的 GPS 点为相对坐标原点 (0,0)，将车辆后续的所有 GPS 定位投影转换为相对原点的东向位移（x 轴，单位米）和北向位移（y 轴，单位米）。这为控制算法提供了精准的相对平面坐标。

## 3. 导航控制与 Pure Pursuit 寻迹算法
GNSS 的最终消费端位于 `plan1_gnss.c` 中。实际工程代码抛弃了复杂的 MPC 或 ESKF 融合模型，而是采用了一套极其简练且带有抗噪保护的纯跟踪（Pure Pursuit）控制逻辑。具体实现在 `GpsNavReplay_Process()` 函数中：

### 3.1 目标点选取策略（只寻目标，绝不回头）
- **寻点逻辑**：在当前坐标 `(cx, cy)` 和目标航点之间，如果距离小于前视距离阈值（`GPS_NAV_LOOKAHEAD_DIST`，约 2.5m），或者通过点积投影法判断车体在物理上已经越过了该点，系统就会立刻将目标索引 `g_gps_target_idx` 加 1，锁向下一个点（`plan1_gnss.c` : L243-L282）。
- **终点防冲刺**：到达倒数第一个点附近时，如果进入到站半径或越过终点连线，车辆会立即停止（`plan1_gnss.c` : L212-L240）。

### 3.2 航向误差计算与多级抗噪
获取到目标点后，控制层计算出了目标方位角与当前航向角的偏差 `raw_err_degree`，由于 GNSS 数据本身会存在波动，代码中设计了三级抗噪（`plan1_gnss.c` : L285-L308）：
1. **低通滤波 (A)**：使用 `alpha = 0.25f` 对原始角度偏差进行平滑过渡。
2. **死区处理 (B)**：如果滤波后的误差小于 $2.0^\circ$，直接归零，避免在直线上频繁修正导致蛇行。
3. **暴力限幅 (C)**：将最终的修正角度硬性限制在 $-35.0^\circ$ 到 $+35.0^\circ$ 之间，防止过大偏差引起打龟。

### 3.3 动态速度规划
控制小车油门（PWM）输出时，根据距离和偏角计算出 `target_speed_set`（`plan1_gnss.c` : L310-L327）：
- **基准速度分配**：如果距离大于一定阈值且航向误差很小（$< 10^\circ$），采用快速 `GPS_NAV_SPEED_FAST`，否则使用慢速 `GPS_NAV_SPEED_SLOW`。
- **弯道降速与防卡死**：采用 `speed_factor = 1.0f - (abs_err / 40.0f)` 使弯道减速。为了防止大转弯时减速过多导致电机停摆、原地震颤，强行增加了一个动力保底：`if (speed_factor < 0.40f) speed_factor = 0.40f;`。
