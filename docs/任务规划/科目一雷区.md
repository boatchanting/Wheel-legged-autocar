# Minefield 雷区 (原地旋转控制两周)

## 1. 模块简介
**Minefield** 模块是一个专用于平衡小车的高级运动控制单元。其主要功能是接管小车的航向控制权，实现平滑、精准的 **原地旋转两周 (720°)** 动作。

该模块采用了 **梯形速度规划 (Trapezoidal Velocity Profile)** 算法，实现了“柔和起步 -> 匀速旋转 -> 线性减速 -> 精准停车”的控制效果，有效防止小车在剧烈旋转时因离心力或加减速过猛而倒地。

## 2. 文件结构
| 文件名 | 类型 | 描述 |
| :--- | :--- | :--- |
| `minefield.c` | 源文件 | 包含状态机逻辑、速度规划算法及内部状态变量。 |
| `minefield.h` | 头文件 | 对外接口声明、全局标志位定义。 |

## 3. 配置参数 (Macros)
以下参数位于 `minefield.c` 顶部，用户可根据车身机械特性进行调整：

| 宏定义名称 | 默认值 | 单位 | 说明 |
| :--- | :--- | :--- | :--- |
| **`SPIN_TARGET_ANGLE`** | `720.0f` | 度(°) | 动作的总旋转角度。 |
| **`SPIN_MAX_SPEED`** | `220.0f` | °/s | 旋转过程中的最高角速度。数值越大转得越快，但也越容易失稳。 |
| **`SPIN_ACCEL_STEP`** | `0.6f` | - | 加速度斜率控制。每次调用(2ms)增加的速度值。`0.6` 约等于 `300°/s²`。数值越小起步越柔和。 |
| **`SPIN_DECEL_ANGLE`** | `180.0f` | 度(°) | 当剩余角度小于此值时，开始线性减速。 |
| **`SPIN_MIN_SPEED`** | `45.0f` | °/s | 最小收尾速度。防止减速后期因电机死区或摩擦力导致小车提前停滞。 |

## 4. API 接口说明

### 4.1 全局变量
```c
extern volatile uint8_t minefield_flag;
```
*   **作用**：动作触发开关。
*   **用法**：外部逻辑（如图像识别完成、按键按下）将此变量置为 `1`。模块检测到后会自动开始动作，并在下一周期自动将其清零。

### 4.2 函数接口

#### `void Minefield_Init(void)`
*   **描述**：初始化模块状态，复位所有积分和速度变量。
*   **调用时机**：系统初始化或急停复位时。

#### `uint8_t Minefield_Is_Active(void)`
*   **描述**：查询当前模块运行状态。
*   **返回**：
    *   `1`: 动作正在执行中（此时应屏蔽外部PID航向环）。
    *   `0`: 动作未执行/已结束。

#### `float Minefield_Spin_Controller(...)`
*   **描述**：模块的核心处理函数，必须在定时中断中周期性调用。
*   **参数**：
    *   `gyro_z_deg`: 当前Z轴角速度实测值（单位：°/s，需滤波后数据）。
    *   `dt_s`: 调用周期时间（单位：秒，例如 2ms 传 `0.002f`）。
    *   `current_yaw_deg`: 当前IMU解算的偏航角（用于动作结束时重置目标）。
    *   `target_yaw_ptr`: 指向全局航向目标变量的指针（例如 `&g_initial_yaw`）。
*   **返回**：计算出的 **期望角速度**。直接输送给角速度环（内环）PID。
*   **注意**：该函数内部实现了状态机和积分运算，切勿在非中断环境中调用。

## 5. 核心算法原理

模块通过以下三个阶段实现平滑控制：

1.  **旁路控制 (Bypass Control)**：
    当动作激活时，模块会接管 `g_initial_yaw` 对航向的控制，暂时屏蔽“转向角度环（外环）”，直接向“转向角速度环（内环）”发送指令。

2.  **陀螺仪积分测距**：
    利用公式 $\theta = \sum (\omega \times \Delta t)$，在 2ms 中断中实时累加 Z 轴角速度，计算实际转过的角度，从而摆脱对编码器或磁力计的依赖。

3.  **速度规划 (S-Curve / Trapezoid)**：
    *   **加速段**：利用斜坡函数（Ramp）限制速度变化率，防止倒地。
    *   **巡航段**：保持 `SPIN_MAX_SPEED` 匀速旋转。
    *   **减速段**：当 `剩余角度 < SPIN_DECEL_ANGLE` 时，目标速度随距离线性减小，直至 `SPIN_MIN_SPEED`。

4.  **无缝退出 (Smooth Handover)**：
    动作完成后，模块立即读取当前的 `euler_angle.yaw` 并将其赋值给 `g_initial_yaw`。这确保了切回正常PID控制时，误差为0，避免小车出现回弹或抖动。

## 6. 集成指南

### 6.1 包含头文件
在 `isr.c` 或主控文件中包含：
```c
#include "minefield.h"
```

### 6.2 触发动作
在业务逻辑中（例如 `main.c` 或图像处理任务）：
```c
if (vision_detected_marker == 1) {
    minefield_flag = 1; // 触发旋转
    vision_detected_marker = 0;
}
```

### 6.3 中断调用 (ISR)
在 2ms 或 5ms 的周期中断中集成（参考 `pit0_ch0_isr`）：

```c
// 1. 获取指令
float spin_cmd = Minefield_Spin_Controller(filtered_gyro_z, 0.002f, euler_angle.yaw, &g_initial_yaw);

// 2. 仲裁逻辑
if (Minefield_Is_Active()) {
    // 旋转模式：使用 Minefield 计算出的平滑速度
    final_turn_cmd = spin_cmd; 
} else {
    // 普通模式：使用常规 PID 角度环输出
    final_turn_cmd = turn_angle_loop_out; 
}

// 3. 执行内环
turn_gyro_loop_out = Turn_Gyro_Loop_Control(final_turn_cmd, filtered_gyro_z);
```

## 7. 调试建议

| 现象 | 可能原因 | 调整建议 |
| :--- | :--- | :--- |
| **启动时车身剧烈晃动** | 加速度过大 | 减小 `SPIN_ACCEL_STEP` (如 0.6 -> 0.4)。 |
| **旋转速度过快导致倒地** | 最大速度过高 | 减小 `SPIN_MAX_SPEED` (如 220 -> 180)。 |
| **动作结束时转角不足** | 摩擦力或积分误差 | 稍微增大 `SPIN_TARGET_ANGLE` (如 720 -> 740) 或 增大 `SPIN_MIN_SPEED`。 |
| **结束时车身回弹** | 目标未重置 | 检查是否正确传入了 `&g_initial_yaw` 指针。 |
| **旋转方向错误** | 电机/陀螺仪定义差异 | 在 `Minefield_Spin_Controller` 返回值处乘以 `-1.0f`。 |
