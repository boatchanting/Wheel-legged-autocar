# CYT4BB 舵机控制说明文档 (四足/多足模式)

### ⚠️ 重要安全说明：软件限幅保护 (强制阅读)
**在任何硬件调试开始前，请务必在代码中设置软件限幅，防止舵机转动超过机械堵转点导致舵机烧毁或结构损坏！**

1.  **限幅定义**：每个舵机通道都有独立的占空比限幅变量：
    - RF: RF_LIMIT_DUTY_MIN/MAX
    - RR: RR_LIMIT_DUTY_MIN/MAX
    - LF: LF_LIMIT_DUTY_MIN/MAX
    - LR: LR_LIMIT_DUTY_MIN/MAX
2.  **堵转检查**：若舵机发出持续的"滋滋"声且无法到达指定角度，说明已发生机械堵转，请立即断电并减小软件限幅范围。
3.  **初始位置**：系统初始化时，所有舵机执行收腿动作（RF/LR=105°, RR/LF=75°），请确保此时机械结构处于安全位置。

## 2. 运动逻辑说明

### 2.1 基础方向与初始化
*   **初始化状态**：系统复位后，执行收腿动作（RF/LR=105°, RR/LF=75°）。
*   **旋转方向**：所有舵机旋转方向遵循 **逆时针 (CCW)** 为正向增加。

### 2.2 联动控制逻辑
当调用 `robot_posture_control(base_angle)` 函数时：
- 当 base_angle = 90° 时，所有舵机处于中位（90°）
- 当 base_angle = 70° 时，各肢体动作如下：

| 舵机名称 | 动作描述 | 角度变化 | 旋转方向 |
| :--- | :--- | :--- | :--- |
| **右前 (PWM1)** | 往下转 | 90° -> 70° | 逆时针 |
| **左前 (PWM3)** | 往上转 | 90° -> 110° | 逆时针 |
| **左后 (PWM4)** | 往下转 | 90° -> 70° | 逆时针 |
| **右后 (PWM2)** | 往上转 | 90° -> 110° | 逆时针 |

## 3. 预设姿态配置

### 3.1 角度与占空比转换关系
在 300Hz 频率下，PWM_DUTY_MAX = 10000 时：
- 0° 对应占空比：3000
- 90° 对应占空比：4500
- 180° 对应占空比：6000

转换公式：
```c
Duty = 3000 * (0.5 + angle/90)
angle = (Duty/3000 - 0.5) * 90
```

### 3.2 初始收腿姿态
- **PWM1 (右前) & PWM4 (左后)**：105°（占空比：5250）
- **PWM2 (右后) & PWM3 (左前)**：75°（占空比：3750）

## 4. API 接口说明

### 4.1 初始化函数
```c
void servo_init_all(void)
```
- 功能：初始化所有舵机并执行收腿动作
- 实现：设置初始占空比并更新内部角度记录

### 4.2 姿态控制函数
```c
void action_contract_legs(void)
```
- 功能：执行收腿动作
- 实现：RF/LR=105°, RR/LF=75°

```c
void robot_posture_control(float base_angle)
```
- 功能：机器人联动控制
- 参数：base_angle 基础参考角度（70-110）

### 4.3 单舵机控制
```c
void servo_write_angle(pwm_channel_enum ch, float angle)
```
- 功能：写入单个舵机角度（带限幅保护）
- 参数：
  - ch：舵机通道（SERVO_MOTOR_PWM1-4）
  - angle：目标角度（0-180）

```c
void servo_get_current_angles(float *angles_array)
```
- 功能：获取当前四个舵机的物理角度
- 输出：数组顺序为[RF, RR, LF, LR]

## 5. 调试常见问题

1.  **动作方向相反**：如果实际观察到动作方向与说明不符，请检查舵机安装方向。可以通过修改 `robot_posture_control` 函数中的加减号来调整方向。
2.  **供电问题**：四个舵机同时动作时，瞬时电流较大，请确保电源能够提供足够的电流（建议2A-5A），并并联大电容稳压。
3.  **占空比范围**：当前代码中占空比范围是 0-10000，对应 0-180°。如需调整，请修改 `_angle_to_duty` 和 `_duty_to_angle` 函数中的转换系数。
4.  **限幅保护**：每个舵机通道都有独立的限幅变量，如果舵机发生堵转，请检查并调整对应通道的限幅值。
