## 2. 软件架构与运动解算

本工程采用 **"查表法" (Look-up Table)** 进行运动学解算，而非实时的逆运动学浮点运算，以提高在 MCU 上的运行效率。

### 2.1 查表机制
代码定义了两个核心查表函数，用于将物理高度（cm）和角度（degree）转换为 PWM 占空比的偏移量。

*   **高度控制 (`high_control_table`)**
    *   **输入**: 目标高度 `p` (cm)。
    *   **逻辑**: 根据 `P_min`, `P_max`, `P_step` 计算索引，查 `pwm_high_table` 表。
    *   **输出**: 更新全局变量 `pwm_high`。
    *   **异常处理**: 若超出范围，`pwm_high` 设为 10000（错误标记）。

*   **复合角度控制 (`servo_control_table`)**
    *   **输入**: 目标高度 `p` (cm) + 目标角度 `degree` (度)。
    *   **逻辑**: 二维查表 `pwm_table_1`。
    *   **输出**: 更新全局变量 `pwm_angle`。
    *   **去耦合**: 函数内部会自动减去 `pwm_high` 分量，使得 `pwm_angle` 仅代表纯角度变化所需的 PWM 差值。

## 3. 角度控制原理

### 3.1 占空比与角度换算
代码使用线性公式进行角度与 PWM Duty 的转换：
*   **斜率 (Slope)**: `33.3333f`
    *   这意味着每改变 **1度**，PWM Duty 值变化约 **33.33**。
    *   对应关系推测：若 PWM 周期计数为 20000 (20ms)，且 500-2500us 对应 0-180度，则精度范围通常较大。此处 33.33 的系数需配合具体的 PWM 初始化频率理解。
*   **基准值**: `SERVO_MOTOR_PWMx_90`
    *   这是每个舵机处于 **90度物理中位** 时对应的 PWM Duty 值。

### 3.2 独立限幅保护
为了防止机械结构卡死，代码在 `servo_write_duty` 和 `servo_write_angle` 中实施了**通道独立限幅**。
*   **LF (PWM1)**: 受 `LF_LIMIT_DUTY_MIN` / `LF_LIMIT_DUTY_MAX` 限制。
*   **RF (PWM2)**: 受 `RF_LIMIT_DUTY_MIN` / `RF_LIMIT_DUTY_MAX` 限制。
*   **RR (PWM3)**: 受 `RR_LIMIT_DUTY_MIN` / `RR_LIMIT_DUTY_MAX` 限制。
*   **LR (PWM4)**: 受 `LR_LIMIT_DUTY_MIN` / `LR_LIMIT_DUTY_MAX` 限制。

> **注意**: 如果舵机运行到某个角度停止并发出异响，请检查对应的 LIMIT 宏定义是否超出了机械极限。

## 4. 核心 API 说明

### 4.1 基础控制
#### `void servo_write_angle(pwm_channel_enum ch, float angle)`
*   **功能**: 将指定舵机转动到绝对角度（逻辑角度 0~180度）。
*   **特性**:
    1. 自动根据 `SERVO_MOTOR_PWMx_90` 计算目标 Duty。
    2. 应用软件限幅。
    3. 反向计算实际输出角度并更新到 `current_angles` 数组，便于后续读取。
*   **参数**: `ch` (通道宏), `angle` (浮点角度)。

#### `void servo_write_duty(pwm_channel_enum ch, int32 duty)`
*   **功能**: 直接写入 PWM 寄存器值（底层调试用）。
*   **特性**: 依然包含限幅保护，并会同步更新角度记录。

### 4.2 状态读取
#### `void servo_get_current_angles(float *angles_array)`
*   **功能**: 获取当前所有舵机的实际角度。
*   **重要**: 该函数的输出数组顺序进行了重排，以匹配上层算法（如姿态解算）的顺序：
    *   `angles_array[0]` -> **RF (右前)**
    *   `angles_array[1]` -> **RR (右后)**
    *   `angles_array[2]` -> **LF (左前)**
    *   `angles_array[3]` -> **LR (左后)**
*   **警告**: 调用此函数前必须确保传入的数组至少包含 4 个 float 元素，否则会导致内存越界。

### 4.3 辅助功能
#### `void update_servo_angle(uint8_t servo_index, uint16_t current_duty)`
*   **功能**: 根据当前的 PWM 值反推角度。
*   **特性**: 考虑了 `servo_direction` (方向极性)，用于处理安装方向相反的舵机（例如左侧舵机 Duty 增加是伸腿，右侧舵机 Duty 增加是收腿）。

## 6. 舵机执行器与平滑控制 (Servo Executor)

本模块 (`servo_executor.c`) 充当运动控制核心，负责将高度、速度（俯仰补偿）、转向（侧倾/偏航）三个维度的控制量混合，并通过**斜率限制算法**将突变的目标值转化为平滑的舵机动作，从而保护机械结构并减少电流冲击。

### 6.1 控制接口变量
上层应用层不直接操作 PWM，而是通过修改以下全局变量来控制机器人的姿态与运动：

| 变量名 | 类型 | 含义 | 更新来源 |
| :--- | :--- | :--- | :--- |
| `servo_height` | `float` | 目标机身高度 (cm) | 导航逻辑或定高算法，**自动查表更新** `g_target_pwm_high` |
| `g_target_pwm_speed_adj` | `int16` | 速度/俯仰补偿量 (PWM差值) | 速度环 PID 或 前馈控制 (控制前后腿差动) |
| `g_target_pwm_angle_adj` | `int16` | 转向/侧倾补偿量 (PWM差值) | 转向环 PID 或 姿态传感器 (控制左右腿差动) |

> **注意**: `g_target_pwm_high` 由 `servo_executor_update` 函数内部调用 `high_control_table(servo_height)` 自动计算，无需手动赋值。

### 6.2 运动混合逻辑 (Mixing Logic)
执行器将三个维度的输入混合为四个舵机的最终目标占空比：

1.  **高度分量 (Base)**: 四腿同向动作。
    *   所有腿 = `基准90度` + `方向` * `高度PWM`
2.  **速度/俯仰分量 (Speed)**: 前后腿反向差动。
    *   前腿 (LF, RF) = Base **+** `速度补偿`
    *   后腿 (RR, LR) = Base **-** `速度补偿`
    *   *效果：改变机身俯仰角，用于加速时的重心前压或减速时的后坐。*
3.  **转向/姿态分量 (Angle)**: 左右/交叉腿差动。
    *   LF (左前) / RF (右前) **-=** `角度补偿`
    *   RR (右后) / LR (左后) **+=** `角度补偿`
    *   *效果：产生侧倾或偏航力矩（具体取决于机械结构与`SERVO_MOTOR_PWMx_DIR`的定义），用于辅助转向或抗侧倾。*

### 6.3 斜率限制算法 (Slope Limiting)
为了防止舵机剧烈抽搐，代码未直接将混合后的目标值写入硬件，而是采用了**增量平滑算法**：

*   **核心参数**:
    *   `acc_limit`: 单次循环最大允许增加的 PWM 值（加速/伸腿速率）。
    *   `dec_limit`: 单次循环最大允许减小的 PWM 值（减速/收腿速率）。

*   **更新公式**:
    ```c
    // 伪代码演示
    Error = Target - Last_Value;
    Step = Constrain(Error, -dec_limit, acc_limit); // 限制单步变化量
    Current = Last_Value + Step;
    Last_Value = Current; // 记忆当前值用于下一次计算
    ```

*   **调试建议**:
    *   如果动作**迟滞/拖泥带水**：增大 `acc_limit` 和 `dec_limit`。
    *   如果动作**抖动/电流过大**：减小 `acc_limit` 和 `dec_limit`。
    *   该参数与函数的调用频率强相关（如 5ms 调用一次 vs 20ms 调用一次，参数需相应调整）。

### 6.4 集成与调用流程

在主程序（`main.c` 或 定时中断）中，应按照以下顺序调用：

1.  **系统初始化**:
    ```c
    // 1. 设置初始高度
    servo_height = 10.0f; // 设定初始高度 10cm
    // 2. 初始化执行器 (会自动查表并让舵机归位)
    servo_executor_init();
    ```

2.  **控制循环 (建议 10ms - 20ms 周期)**:
    ```c
    // --- 步骤 A: 上层算法计算 (示例) ---
    // 根据传感器或遥控更新高度
    servo_height = get_user_height_input(); 
    
    // 计算速度补偿 (例如：速度越快，pwm_speed_adj 越大，压低车头)
    g_target_pwm_speed_adj = (int16)(current_speed * Kp_speed);
    
    // 计算转向补偿 (例如：陀螺仪检测到侧倾，进行反向补偿)
    g_target_pwm_angle_adj = (int16)(gyro_roll_error * Kp_roll);

    // --- 步骤 B: 执行底层更新 ---
    // 执行器负责：查表 -> 混合 -> 平滑限幅 -> 写入硬件
    servo_executor_update();
    ```

### 6.5 双重限幅保护机制
本模块实现了两道安全防线：
1.  **动态平滑**: 通过 `acc_limit/dec_limit` 防止**控制信号**突变导致的机械冲击。
2.  **硬性限幅**: 在最终写入 `pwm_set_duty` 前，强制调用 `Float_Constrain` 限制在 `LF_LIMIT_DUTY_MIN/MAX` 范围内，防止**最终位置**超出机械死点。
