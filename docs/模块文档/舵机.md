# CYT4BB 舵机控制说明文档 (四足/多足模式)

### ⚠️ 重要安全说明：软件限幅保护 (强制阅读)
**在任何硬件调试开始前，请务必在代码中设置软件限幅，防止舵机转动超过机械堵转点导致舵机烧毁或结构损坏！**

1.  **限幅定义**：在 `SERVO_MOTOR_L_MAX` 和 `SERVO_MOTOR_R_MAX` 中定义该引脚允许的最大旋转范围。
2.  **堵转检查**：若舵机发出持续的“滋滋”声且无法到达指定角度，说明已发生机械堵转，请立即断电并减小软件限幅范围。
3.  **初始位置**：系统初始化时，所有舵机强制归位至 **90度**（中位），请确保此时机械结构处于安全半程位置。

## 1. 硬件连接与引脚映射

本例程针对四足/四肢结构，定义如下：

| 模块位置 | 定义宏 | 推荐引脚 (TCPWM) | 物理管脚 |
| :--- | :--- | :--- | :--- |
| **右前 (Right Front)** | `SERVO_MOTOR_PWM1` | `TCPWM_CH09_P05_0` | P05_0 |
| **右后 (Right Rear)** | `SERVO_MOTOR_PWM2` | `TCPWM_CH10_P05_1` | P05_1 |
| **左前 (Left Front)** | `SERVO_MOTOR_PWM3` | `TCPWM_CH11_P05_2` | P05_2 |
| **左后 (Left Rear)** | `SERVO_MOTOR_PWM4` | `TCPWM_CH12_P05_3` | P05_3 |

## 2. 运动逻辑说明

### 2.1 基础方向与初始化
*   **初始化状态**：系统复位后，`PWM1` 至 `PWM4` 统一输出 **90度** 对应的占空比。
*   **旋转方向**：所有舵机旋转方向遵循 **逆时针 (CCW)** 为正向增加。

### 2.2 动作映射 (当指令从 90° 变化至 70° 时)
当软件逻辑给定一个 -20° 的偏移量（即从 90° 变化到 70° 趋势）时，各肢体动作如下：

| 舵机名称 | 动作描述 | 角度变化 | 旋转方向 |
| :--- | :--- | :--- | :--- |
| **右前 (PWM1)** | 往下转 | 90° -> 70° | 逆时针 |
| **左前 (PWM3)** | 往上转 | 90° -> 110° | 逆时针 |
| **左后 (PWM4)** | 往下转 | 90° -> 70° | 逆时针 |
| **右后 (PWM2)** | 往上转 | 90° -> 110° | 逆时针 |

## 3. 预设姿态占空比配置

针对收腿和伸腿动作，直接操作底层占空比 `duty` (范围 0-10000)：

#### **姿态 A：收腿 (Contract Legs)**
*   **PWM1 (右前) & PWM4 (左后)**：`5000`
*   **PWM2 (右后) & PWM3 (左前)**：`4000`

#### **姿态 B：伸腿 (Extend Legs)**
*   **PWM1 (右前) & PWM4 (左后)**：`3000`
*   **PWM2 (右后) & PWM3 (左前)**：`6000`

## 4. 示例代码实现

### 4.1 软件限幅与宏定义
```c
// 软件安全限幅 (根据机械结构实际情况修改)
#define SERVO_LIMIT_MIN             (60)   
#define SERVO_LIMIT_MAX             (120)

// 舵机角度转换为占空比宏
#define GET_SERVO_DUTY(angle)       ((float)PWM_DUTY_MAX/(1000.0/(float)SERVO_MOTOR_FREQ)*(0.5+(float)(angle)/90.0))
```

### 4.2 初始化逻辑
```c
void robot_servo_init(void)
{
    // 初始化频率通常为 50Hz - 300Hz
    uint32 init_duty = (uint32)GET_SERVO_DUTY(90); // 初始 90 度
    
    pwm_init(SERVO_MOTOR_PWM1, SERVO_MOTOR_FREQ, init_duty);
    pwm_init(SERVO_MOTOR_PWM2, SERVO_MOTOR_FREQ, init_duty);
    pwm_init(SERVO_MOTOR_PWM3, SERVO_MOTOR_FREQ, init_duty);
    pwm_init(SERVO_MOTOR_PWM4, SERVO_MOTOR_FREQ, init_duty);
}
```

### 4.3 预设动作函数
```c
// 收腿动作
void action_contract_legs(void)
{
    pwm_set_duty(SERVO_MOTOR_PWM1, 5000); // 右前
    pwm_set_duty(SERVO_MOTOR_PWM4, 5000); // 左后
    pwm_set_duty(SERVO_MOTOR_PWM2, 4000); // 右后
    pwm_set_duty(SERVO_MOTOR_PWM3, 4000); // 左前
}

// 伸腿动作
void action_extend_legs(void)
{
    pwm_set_duty(SERVO_MOTOR_PWM1, 3000); // 右前
    pwm_set_duty(SERVO_MOTOR_PWM4, 3000); // 左后
    pwm_set_duty(SERVO_MOTOR_PWM2, 6000); // 右后
    pwm_set_duty(SERVO_MOTOR_PWM3, 6000); // 左前
}
```

## 5. 调试常见问题

1.  **动作方向相反**：如果实际观察到动作方向与说明文档不符，请检查舵机在安装时是否镜像翻转。若发生镜像，需在代码中将 `(90 + offset)` 修改为 `(90 - offset)`。
2.  **供电抖动**：四足机器人四个舵机同时动作时，瞬时电流可达 2A-5A，请务必使用 **动力电池** 供电，并并联大电容稳压。
3.  **占空比数值注意**：文中的 5000、4000 等数值是基于 `PWM_DUTY_MAX = 10000` 定义的。如果修改了底层 `zf_driver_pwm.h` 中的最大值，请等比例换算。
