# IPS200 (2寸) 显示模块使用说明文档

## 1. 简介
本例程用于驱动 2寸 IPS 显示屏，支持 **SPI串行** 与 **8位并行** 两种通讯模式。代码提供了丰富的图形库函数，包括图片显示、中英文字符显示、各类数值（整型/浮点）显示、波形绘制以及几何图形绘制，非常适合用于嵌入式系统的调试数据监控与人机交互界面开发。

---

## 2. 硬件连接说明

请根据实际使用的通信模式（SPI 或 并口）检查接线。
**注意：** 错误的接线可能导致屏幕白屏、花屏或无法点亮。

| 模块管脚 | 单片机管脚说明 | 备注 |
| :--- | :--- | :--- |
| **BL** | 背光控制引脚 | 查看 `zf_device_ips200_parallel8.h` 中 `IPS200_BL_PIN` 宏定义 |
| **CS** | 片选引脚 | 查看 `IPS200_CS_PIN` 宏定义 |
| **RST** | 复位引脚 | 查看 `IPS200_RST_PIN` 宏定义 |
| **RS** | 命令/数据选择 | 查看 `IPS200_RS_PIN` 宏定义 |
| **WR** | 写控制 (并口用) | SPI模式下通常接高电平或悬空，具体看原理图 |
| **RD** | 读控制 (并口用) | 同上 |
| **D0-D7** | 数据总线 | 并口模式连接8根线；SPI模式通常只用 D0/D1 (SCL/SDA) |
| **GND** | 电源地 | 必须与单片机共地 |
| **3V3** | 电源正 | 必须接 3.3V，**严禁接 5V** |

## 3. 软件配置与初始化

在 `main` 函数中，必须按照以下步骤进行初始化：

### 3.1 接口模式选择
在代码顶部宏定义处选择通信协议：
```c
// 选择 SPI 模式 (接线少，速度适中)
#define IPS200_TYPE     (IPS200_TYPE_SPI)       
// 或选择 并口模式 (接线多，刷新速度快)
// #define IPS200_TYPE     (IPS200_TYPE_PARALLEL8) 
```

### 3.2 系统与屏幕初始化
```c
int main(void)
{
    // 1. 基础系统初始化
    clock_init(SYSTEM_CLOCK_250M); // 时钟配置
    debug_init();                  // 调试串口初始化
    
    // 2. 屏幕参数配置
    ips200_set_dir(IPS200_PORTAIT);              // 设置方向：IPS200_PORTAIT (竖屏) 或 IPS200_LANDSCAPE (横屏)
    ips200_set_color(RGB565_RED, RGB565_BLACK);  // 设置默认颜色：(前景色, 背景色)
    
    // 3. 硬件初始化
    ips200_init(IPS200_TYPE);      // 传入之前定义的接口类型
    
    // ... 进入主循环
}
```

## 4. 功能函数详解

### 4.1 基础清屏与填充
在绘制新界面前，通常需要清除旧内容。
*   **清屏**：`ips200_clear();`  
    清除屏幕内容，通常变为默认背景色。
*   **全屏填充**：`ips200_full(Color);`  
    *示例*：`ips200_full(RGB565_GRAY);` 将全屏涂成灰色。

### 4.2 图片显示
显示预先取模好的 RGB565 格式图片数组。
```c
ips200_show_rgb565_image(x, y, image_addr, src_w, src_h, disp_w, disp_h, 0);
```
*   **x, y**: 显示起始坐标。
*   **src_w, src_h**: 原图的宽度和高度。
*   **disp_w, disp_h**: 在屏幕上显示的实际宽高（支持缩放）。

### 4.3 字符与汉字显示
*   **英文字符串**：
    ```c
    ips200_show_string(x, y, "String");
    ```
*   **汉字显示**：
    需预先对汉字取模生成数组。
    ```c
    ips200_show_chinese(x, y, size, data_ptr, count, color);
    ```
    *   `size`: 字体大小（如16）。
    *   `count`: 汉字数量。

### 4.4 数值显示 (核心调试功能)
支持多种格式的数值显示，自动处理负号。

#### 浮点数 (float)
```c
ips200_show_float(x, y, float_num, int_len, dec_len);
```
*   **int_len**: 整数部分显示的位数。
*   **dec_len**: 小数部分显示的位数。
*   *示例*：`ips200_show_float(0, 0, 3.14159, 2, 4)` -> 显示 " 3.1416"

#### 整数 (int/uint)
支持 `int8/16/32` 和 `uint8/16/32`。
```c
ips200_show_int(x, y, number, length);   // 有符号
ips200_show_uint(x, y, number, length);  // 无符号
```
*   **length**: 显示占用的字符位数，不足补空格。

### 4.5 波形显示
用于观察传感器数据变化趋势（如电感值、陀螺仪数据）。
```c
ips200_show_wave(x, y, data_ptr, data_len, max_val, disp_w, disp_h);
```
*   **x, y**: 波形图左上角坐标。
*   **data_ptr**: 数据数组指针（如 `int16_t data[]`）。
*   **data_len**: 数组中数据的个数。
*   **max_val**: 数据的归一化最大值（超过此值将被截断）。
*   **disp_w**: 波形在屏幕上显示的宽度（像素）。
*   **disp_h**: 波形在屏幕上显示的高度（像素）。

### 4.6 几何绘图
*   **画线**：
    ```c
    ips200_draw_line(x1, y1, x2, y2, color);
    ```
    连接 (x1, y1) 到 (x2, y2) 的直线。

## 5. 例程逻辑说明

代码中的 `while(true)` 循环展示了动态刷新的效果：

1.  **开机LOGO**：显示 Seekfree 图片，停留 1.5秒。
2.  **数据看板**：
    *   显示静态字符串和汉字。
    *   **浮点数测试**：展示了正负浮点数及其位宽控制。
    *   **整数测试**：展示了从 int8 到 uint32 各类整数的显示范围。
3.  **波形演示**：
    *   构建了一个三角波数组 `data`。
    *   演示了两次波形绘制，分别改变了显示比例（压缩与拉伸）。
4.  **图形动画**：
    *   通过 `for` 循环不断改变直线的终点坐标，配合延时，实现了类似雷达扫描的动画效果。
5.  **纯色轮播**：
    *   依次全屏填充红、绿、蓝、白四种颜色，用于检查屏幕坏点或色彩表现。

## 6. 开发建议与注意事项

1.  **刷新率控制**：
    *   不要在 `while` 循环中重复刷新不变的内容（如标题文字、背景框），应放在循环外绘制一次。
    *   循环内只刷新变化的数据（如传感器数值），以减少闪烁并提高运行效率。
2.  **坐标系**：
    *   屏幕左上角为 (0, 0)。
    *   x 轴向右增加，y 轴向下增加。
    *   注意不要绘制到屏幕分辨率范围之外，否则可能导致程序死机或显示异常。
3.  **数据类型匹配**：
    *   使用 `ips200_show_int` 时，请确保传入的变量类型与函数期望的范围一致，避免溢出。
4.  **延时函数**：
    *   例程中使用了 `system_delay_ms` 来展示效果。在实际控制车辆或机器人时，应尽量避免在主循环使用长延时，以免阻塞控制逻辑。
