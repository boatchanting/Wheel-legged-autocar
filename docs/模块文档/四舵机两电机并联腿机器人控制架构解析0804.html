四舵机两电机并联腿机器人控制架构解析（0804）

对象：CYT4BB，四个并联腿舵机（LF/RF/RR/LR）+ 左右两个轮毂电机的两轮自平衡机器人。本文以 pid-new.c/.h、servo.c/.h、servo_executor.c/.h、main_cm7_0.c 为主，另外沿调用链核对了 1 ms PIT ISR 与初始化代码，以还原实际时序。

一句话结论：系统是“实时中断闭环、主循环任务编排、场景 profile 参数调度、舵机目标向量合成”的分层架构。两电机负责纵向平衡/行驶/偏航，四舵机负责车身高度、俯仰前馈、转向侧倾及特殊动作；最终每个执行器都经过限幅、斜率限制和安全仲裁。

1. 总体控制链路

闭环的主反馈来自编码器速度、EKF 俯仰/横滚/偏航和 IMU 陀螺仪。主循环只消费 ISR 置位的标志，执行 WiFi/示波器/屏幕、视觉触发、导航录制与复现启动等非实时工作。

3. 两电机平衡与行驶控制

3.1 三层纵向串级环

速度环（舵机，9 ms） e_v = target_speed - LPF(actual_speed) u_servo = PID_v(e_v)，写入 g_target_pwm_speed_adj 角度环（3 ms） target_pitch = ANG_MECH_ZERO - speed_loop_out（当前 ISR 传入 speed_loop_out=0） u_angle = -PID_pitch(target_pitch - pitch) 角速度环（1 ms） e_g = angle_loop_out - gyro_pitch u_balance = PID_gyro(e_g) + sign(e_g)·GYR_DEAD_ZONE

当前 CAR_SELECT=3 的基础参数为：舵机速度 Kp=-4.5, Ki=0, Kd=-0.17, max=2000；俯仰角 -12,0,-13.3333,max=8000,机械零点=-3°；俯仰角速度 -16,0,0,max=9000。这是一套以 PD 为主、积分关闭的自平衡控制器。

速度测量先做三点加权滤波 0.6·v(k)+0.3·v(k-1)+0.1·v(k-2)。速度环存在自适应 Kp：误差越大倍率从约 0.4 平滑接近 1.0；ACCEL profile 还可通过 ACCEL_FF_MODE_KP 临时把 Kp 乘到最高 1.6。

3.2 电机矢量融合

drive_ff = brake_ff + accel_ff_effective pwm_left = gyro_loop_out + drive_ff + turn_gyro_loop_out pwm_right = -gyro_loop_out - drive_ff + turn_gyro_loop_out 两路统一限幅到 ±OUR_PWM_MAX_LIMIT；电机禁用或倒地时强制置零。

因此平衡项是左右反向差动，驱动前馈也是左右反向差动，转向项是左右同向叠加。转向角速度环输入来自偏航角度外环，或雷区旋转控制器的覆盖指令。

4. 四舵机并联腿目标合成

速度/俯仰g_target_pwm_speed_adj前腿同号、后腿反号：加速前倾=前腿伸展+后腿收缩

执行器最终计算为 target_final_duty = duty_90 + DIR·height + DIR·speed ± angle + DIR·turn_roll ± roll。其中 PWM1~4 按 LF/RF/RR/LR 定义，CAR_SELECT=3 中位分别为 4550/4700/4700/4800，方向为 +1/-1/+1/-1，舵机频率 300 Hz。

5. 舵机执行器与查表

high_control_table 将高度映射到 394 点 pwm_high_table；servo_control_table 通过高度×腿角二维表输出角度差。当前运行路径主要使用高度一维表，普通转向主动侧倾先按 a_lat=v·ω 计算目标滚转角，再用 Δh=half_track·tan(roll) 和高度表转为四路差动 PWM。

servo_executor_update 每 1 ms 更新：读取当前高度、合成四路目标、按运行场景动态计算加/减速斜率、对每路做 last + constrain(target-last,-dec,+acc)，最后按 LF/RF/RR/LR 独立限幅并写入 PWM。NORMAL/ACCEL/BRAKE 的基准执行器参数分别约为 (10,10)、(22,16)、(14,28) duty/ms；误差/速度越大还会增加斜率，最大增量 60/95/80。

6. 刹车、加速与场景 Profile

6.1 刹车前馈

Brake_Feedforward_Update 根据目标降速、实际超速、速度区间和持续 tick 数分级：轻/中/重刹；目标过零、目标归零、CH5 急停和导航强停可直接提高等级。输出约为 -gain·actual_speed，再做最大值和斜率限制，并有零速迟滞、超速计数、导航强停寿命 tick、复位锁。

默认档前馈约为 gain=4/10/22、max=800/1600/3500；导航强停可渐变到 gain=80、max=8200。刹车 PWM 超过 2500 时，速度环强制给反后坐支撑 180 duty 并清积分；超过 2500 的侧倾输出被清零。

6.2 加速前馈

只在复现运行、目标速度明显抬升且没有特殊任务/强刹时生成。以速度缺口乘 gain（默认 10）得到 PWM，峰值 3000，9 ms 周期斜率上升 800、下降 650；可选 PWM 直接叠加或 Kp 增强。最终仲裁规则是“刹车主导、轻刹保留 35% 加速前馈、无刹车全量加速前馈”。

6.3 Profile 调度

上层只调用 Control_Profile_RequestMode 请求 NORMAL/ACCEL/BRAKE；1 ms 更新器用 alpha=0.12（PID）、0.10（前馈）、0.18（限幅）追踪目标，避免切档冲击。ApplyNow 用于上电/复位。Profile 同时覆盖六个 PID、刹车/加速前馈和舵机执行器斜率。

7. 安全状态与任务接管

  • 初始化门控：偏航未初始化时不输出转向环，舵机执行器也不运行。
  • 倒地保护：启动 2 s 后，俯仰相对机械零点超过 ±70° 判定倒地；清电机 PWM、PID 运行态、前馈和导航复现，进入 g_fallen。
  • 跳跃保护：跳跃时冻结惯导速度，电机按跳跃阶段执行专用逻辑，舵机切换到 servo_jump_executor。
  • 特殊任务互斥：雷区、颠簸、PVC、桥、坡、三级跳、推车等任务会屏蔽加速前馈或清主动侧倾，防止多个模块抢写同一执行量。
  • 刹车安全：电机禁用、倒地、跳跃时释放刹车前馈；前馈和加速前馈最终统一仲裁再限幅。

8. 当前实现的关键问题（按风险排序）

P0：舵机角度接口符号/顺序不一致。update_servo_angle 使用 DIR，servo_write_angle 与 servo_write_duty 的角度回算未使用 DIR；servo_get_current_angles 又把 RF/RR/LF/LR 重排，而其他接口按 LF/RF/RR/LR。必须统一“逻辑角度、duty、物理角度”的坐标合同，否则标定、日志和任务判断可能相反。
P0：执行器状态可能越过限幅。current_duty_* / PWM_CH*_LAST 先保存未限幅值，只有 pwm_set_duty 使用限幅值；目标回到合法区时会出现额外追赶，角度缓存也可能与实际 PWM 不同。应把限幅后的 duty 写回状态。
P1：二维查表失败会沿用旧值。servo_control_table 对 raw=10000 使用旧的 pwm_angle，而不是明确故障值；且它依赖调用前已更新的 pwm_high。应返回有效标志、先显式刷新高度，并对非法输入采用安全中位/保持策略。
P1：Profile 的 applied 语义不严格。Control_Profile_Update1ms 每个 tick 都把 g_control_mode_applied=requested，但参数仍在渐变。建议拆成 requested、transitioning、settled 三态，只有误差小于阈值才报告 settled。
P1：PID 微分/积分与真实 dt 脱钩。误差差分未除以 dt，积分也未乘 dt；当前 Ki 多为 0，仍建议统一改为 dt-aware，并给 D 项加测量微分/低通以降低跳变噪声。
P1：共享浮点量缺少一致性快照。主循环、ISR、Core1 视觉可能同时读写目标速度、侧倾分量和任务标志；32 位浮点在多核/中断交错下可能读到半更新值。建议采用序号锁、双缓冲或短临界区。
P2：实时负载缺少硬预算。1 ms ISR 同时执行 EKF、多个状态机、浮点三角函数、查表和 PWM；已有 profiler，但应把“最大执行时间 < 700 µs、抖动 < 50 µs”纳入验收。

9. 小车详细控制优化方案

P0 先修坐标、状态和限幅，再调参

改造项实施要点验收
统一舵机坐标合同定义唯一枚举 LF/RF/RR/LR；所有写角、写 duty、缓存、遥测均按同序；角度回算统一乘 DIR，并增加单元测试“正高度=伸腿、正侧倾=右侧抬高”。四路静态误差≤1.5°；正负动作方向 100% 一致
限幅闭环化计算候选 duty→独立限幅→把限幅结果写回 PWM_CH*_LAST/current_duty_*→再输出；增加限位到达标志。触边后无积分/斜率追赶；限位不抖动
查表 API 改造返回 {value,valid}；非法高度/角度安全保持上一有效值或回中；调用前显式刷新 pwm_high。越界输入不产生旧值串入；故障可观测
Profile 状态机requested→ramping→settled；切换时保存旧输出，必要时重置 D 历史而不清零目标，做到 bumpless transfer。切换无 PWM 突跳；settled 延迟可测

P1 提高平衡、转向和腿部协调性

  1. 时间归一化 PID：给每个环传入固定 dt（1/3/5/9 ms），积分使用 I+=e·dt，D 使用 (e-e_prev)/dt；D 改为对测量值微分，前置一阶低通（建议 30~50 Hz 俯仰、15~25 Hz 偏航）。
  2. 抗饱和：当角速度环或电机融合达到限幅且误差继续同向时冻结/回算积分；刹车保护清积分时同步清速度滤波历史，避免释放后反冲。
  3. 速度环与舵机姿态解耦：保留当前“速度环只调腿”的策略，但将 speed_loop_out 明确置零并改名为 pitch_target_offset，或者实现真正的慢速俯仰外环，避免维护者误以为速度环输出丢失。
  4. 电机差速标定：对左右电机建立 PWM→加速度/稳态速度地图，按电池电压、载荷做增益调度；增加左右速度差 v_diff 小环补偿直行偏航。
  5. 主动侧倾前馈：继续使用 a_lat=v·ω，但对 v、ω 先限幅和低通；将目标滚转角按速度区间调度（低速 0、高速逐步放大），并在电机饱和、刹车、低电量时降权。
  6. 四腿同步：增加左右平均高度和前后平均高度监控；执行器每 1 ms 使用同一输入快照，目标更新采用 2-phase commit，避免某一路先更新造成瞬时扭矩。

P1 前馈与场景策略

  • 建立实测 F(v,Δv,V_bat) 加速前馈表，替代单一 gain·缺口；起步、出弯、坡道分别使用不同曲线。
  • 刹车采用目标减速度规划（梯形/S 曲线）产生刹车请求，前馈只补偿动力学，不直接由速度跳变决定重刹；导航强停仍保留，但加入最小持续时间与释放速度的状态图。
  • 把 g_brake_active/g_reverse_brake_active/g_special_action_trigger 收敛成单一仲裁器，输出“驱动、刹车、特殊动作”的优先级和原因码，避免多个 if 条件散落。
  • 普通转向主动侧倾与单边桥 Rolling 明确互斥；任务接管时冻结普通侧倾目标并平滑归零，结束时再斜率恢复。

P2 可观测性、验证和工程化

  • 每 10/50 ms 记录环路输入、P/I/D、限幅标志、profile、前馈、四路目标/实际 duty、ISR 最大/平均耗时。
  • 增加离线回放：用编码器+IMU日志复现控制计算，先在 PC 上验证符号、限幅和切档，再上车。
  • 做四组阶跃测试：速度 ±30、±60；航向 ±10°；横滚 ±5°；刹车 220→0。记录上升时间、超调、稳态误差、峰值电流和腿差。
  • 把参数从宏逐步迁移到带版本号的结构体，Flash 存储加入 CRC、范围检查和回滚默认值。

10. 推荐调参顺序与指标

  1. 机械：逐路确认中位、DIR、限位和高度查表单调性。
  2. 传感器：静止测 gyro 零偏，验证 pitch/roll/yaw 符号及 EKF dt。
  3. 内环：只开 Gyro PD，逐步提高 Kp，再加 D；目标是 1 ms 内快速抑制角速度且不高频啸叫。
  4. 中环：调 ANG_KP，再调 ANG_KD；以 ±2° 扰动的恢复时间和超调为准。
  5. 速度/腿：先关闭前馈，调速度环；再小步加入加速前馈和刹车前馈。
  6. 转向与侧倾：先转向角速度内环，再角度外环，最后加入主动侧倾，确认不会抢占单边桥任务。

建议首轮验收目标：平地直立稳态 pitch 误差 RMS≤1.0°；直行左右速度差≤5%；10° 航向阶跃超调≤15%；停车后 300 ms 内速度进入 ±15（当前速度单位）；四路高度差≤0.3 cm；ISR 最大耗时≤700 µs。
