# 桩筒净空模型简化设计

## 目标

路径规划只使用可解释的物理净空：桩筒物理半径、车身半宽和固定额外安全余量。移除平衡腿摆动、车身倾斜、定位误差及独立走廊余量对桩筒净空的叠加。

## 计算模型

```text
禁入半径 = 桩筒半径 + 车身半宽 + 额外安全余量
         = 140 mm + 135 mm + 200 mm
         = 475 mm
```

绕桩控制点的横向偏置与最终路径净空校验必须使用同一个 475 mm 值；不再额外加走廊余量。

## 范围

- 仅修改 `tools/webview_nav_marker速度规划/caculate_path.py` 的桩筒几何净空常量及其测试。
- 不修改 3.5 m/s² 横向加速度预算、速度规划、LQR 限幅或极速掉头逻辑。
- CSV 点位语义保持不变：首个业务点是掉头点，中间点是桩筒，最后一个点是终点且不参与桩筒净空检测。

## 验证

- 增加/更新测试，断言禁入半径和控制点偏置均为 475 mm。
- 以当前的 5 点布局复算，确认不再因 705 mm 净空阈值失败；若仍有曲率或净空失败，应如实报告为该布局在 475 mm 模型下的独立几何限制。
