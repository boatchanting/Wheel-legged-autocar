# 科目二特殊点停车状态机设计

## 目标

修正特殊点接近过程中目标速度过早解除置零的问题。刹车力度沿用遥控停车所使用的普通零速刹车，不启用导航强刹；车辆只有在低速且确认依靠剩余惯性无法进入执行准备圈时，才允许低速补进。

## 圆区定义

- 动态刹车圈：沿用当前 `执行圈 + 刹车余量 + v^2/(2a)` 计算方式及上下限，用于首次进入持续置零状态。
- 执行准备圈：半径 `300 mm`。低速补进车辆进入此圈后，立即再次将目标速度置零。
- 执行圈：半径 `100 mm`。车辆位于圈内且实际速度不高于执行阈值时，才触发特殊动作。

## 状态与数据流

1. 特殊点在动态刹车圈外时，按正常在线速度规划接近。
2. 首次进入动态刹车圈后锁存刹车状态，持续输出 `target_speed_set = 0`。速度降至 `120` 不再自动解除置零。
3. 停车阶段使用底层现有普通零速刹车，与高速反向推遥控速度杆、最终使目标速度归零时的刹车档位一致；导航层不请求强刹。
4. 特殊点的零速刹车锁存一旦建立，必须立即清除并持续抑制加速前馈。不能等待刹车 PWM 达到阈值后才抑制，避免残余加速前馈抵消制动力。
5. 当实际速度已经很低时，计算当前速度对应的预计剩余滑行距离。只有预计停车位置仍明显位于执行准备圈外，才解除置零并输出低速补进速度。
6. 补进过程中一旦进入 `300 mm` 执行准备圈，立即重新锁存置零，不再继续输出补进速度。
7. 进入 `100 mm` 执行圈且实际速度不超过执行阈值后，触发旋转或其他特殊动作。
8. 如果补进期间因定位变化重新远离准备圈，已经发生的准备圈置零仍保持，避免目标速度反复抖动。

## 补进判定

补进必须同时满足：

- 首次零速刹车已经发出；
- 当前不在执行准备圈内；
- 实际速度不高于低速补进准入阈值；
- `当前到中心距离 - 执行准备圈半径` 大于按当前速度和保守减速度估算的剩余滑行距离，并留有判定余量。

该判定表达的是“保持置零将明显停在准备圈外”，而不是简单使用一个速度阈值解除置零。

## 测试要求

- 进入动态刹车圈后，即使速度降到 `120` 以下，只要预计仍能滑入准备圈，就继续输出零速。
- 低速且预计停在准备圈外时，允许输出低速补进速度。
- 补进进入 `300 mm` 准备圈后立即恢复零速。
- 准备圈置零后即使距离抖到圈外，也不得再次补进。
- 只有进入 `100 mm` 执行圈并满足速度条件时才触发动作。
- 整个流程不发出导航强刹请求，普通刹车前馈仍可根据零目标速度正常建立。
- 零速刹车锁存建立时，加速前馈在同一个控制周期内清零；零速刹车锁存保持期间不得重新生成加速前馈。
