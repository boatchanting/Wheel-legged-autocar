# 双轮足并联腿自平衡机器人结构与控制架构说明文档

> [!IMPORTANT]
> **本车（或机器人）既不是普通的四轮车，也不是依靠舵机转向的传统小车，而是一台“对称五连杆并联腿双轮足式自平衡机器人”。**
>
> 为避免在后续开发中引入“当成普通四轮车或舵机转向车写代码”的常识性 Bug，请开发人员在开始编写控制逻辑前，务必仔细阅读并理解本说明文档。

---

## 1. 整车物理结构与运动解算

本机器人的机械结构由**对称的两个五连杆并联腿**以及底部的**对称双轮足**构成。其布局示意如下：

```
       [ 机器人本体机身 (Chassis) ]
        /                       \
     [左腿]                    [右腿]
 (左前LF + 左后LR)         (右前RF + 右后RR)
      \                       /
    [左轮]                  [右轮]
  (左轮电机)              (右轮电机)
```

### 1.1 五连杆并联腿部结构 (Leg Joints)
机器人的左、右腿分别由两个大扭矩舵机（共四个舵机通道）驱动一个五连杆机构。
*   **左腿控制舵机**：左前 (LF) 和 左后 (LR) 
*   **右腿控制舵机**：右前 (RF) 和 右后 (RR)
*   **高度与俯仰解算**：
    *   通过同向或反向协同控制单侧的前后两个舵机，可以改变该侧腿部的**虚拟腿长（高度）**和**虚拟腿角（俯仰）**。
    *   工程中采用**“查表法”（Look-up Table）**来避开高频复杂的逆运动学（IK）运算。
        *   **高度查表 (`high_control_table`)**：根据目标高度 $p$ (cm) 查表得到基准 PWM 偏移量 `pwm_high`。
        *   **高度+角度复合查表 (`servo_control_table`)**：根据高度 and 虚拟腿角进行二维查表，并自动解耦高度分量，用于控制腿部的俯仰姿态。

### 1.2 对称双轮足结构 (Wheel Feet)
腿部底部各装有一个由无刷电机（带 FOC 驱动）控制的轮子。
*   **对称安装**：由于左右两个电机是在车轴两侧对称相反安装的，因此它们的**电信号方向与物理运动方向相反**。
    *   **左轮**：写入正 PWM 时，轮子物理向前转动。
    *   **右轮**：写入负 PWM 时，轮子物理向前转动。
*   **差速转向 (Differential Steering)**：
    *   **本车没有用于偏航转向的物理转向舵机**。
    *   整车的转向（Yaw）**完全依赖左右两个轮子的差速驱动**来实现。
    *   在编写转向控制逻辑时，必须通过改变左右电机的差动电压/占空比来产生转弯力矩，而非期望控制任何舵机。

## 2. 轮-腿解耦自平衡控制架构

本车采用“轮足负责纵向平衡与横向转向，腿部负责高度与纵向速度”的**解耦控制架构**。这是与传统两轮平衡车最核心的区别。

### 2.1 轮足控制：直立平衡与差速转向
轮子（无刷电机）仅用于执行高频（1ms）的**直立平衡环**和**转向环**，不直接参与速度控制环的计算。

#### 1) 纵向自平衡 (Pitch Balance)
*   **目标**：保持车身在机械零点（平衡点 `compensation`）直立。
*   **控制链**：
    $$\text{机械零点} \longrightarrow [平衡角度环(3ms)] \longrightarrow \text{目标角速度} \longrightarrow [平衡角速度环(1ms)] \longrightarrow \text{平衡输出 } gyro\_loop\_out$$
*   **注**：传统平衡车的速度环输出会作为平衡角度环的输入（靠倾斜车身加速），但在此架构中，速度控制已被解耦到腿部，因此**平衡角度环的输入直接设为 0**（不引入速度环输出）。
*   **输出融合**：`gyro_loop_out` 对称异号叠加到左右轮：
    *   左轮 PWM 叠加 $+gyro\_loop\_out$
    *   右轮 PWM 叠加 $-gyro\_loop\_out$

#### 2) 横向差速转向 (Yaw Steering)
*   **目标**：追踪期望的航向角（Yaw）或转弯角速度。
*   **控制链**：
    $$\text{偏差角度} \longrightarrow [转向角度环(3ms)] \longrightarrow \text{目标转弯角速度} \longrightarrow [转向角速度环(1ms)] \longrightarrow \text{转向输出 } turn\_gyro\_loop\_out$$
*   **输出融合**：由于电机对称安装，为了让车辆旋转（两轮物理反向旋转），混控时必须使用**同号**叠加：
    *   左轮 PWM 叠加 $+turn\_gyro\_loop\_out$
    *   右轮 PWM 叠加 $+turn\_gyro\_loop\_out$

---

### 2.2 腿部控制：姿态调节与速度控制
四个舵机（LF, LR, RF, RR）通过控制腿部的形态，负责**速度（俯仰重心）**和**横滚平衡（姿态）**控制。

#### 1) 纵向速度控制 (Speed Control)
传统平衡车需要通过电机差速“主动滑行”来改变倾角加速。而本车通过**调节腿部前后长短差**来主动改变重心：
*   **控制逻辑**：当目标速度大于当前速度时（需要加速），速度环 `Servo_Speed_Control` 输出正的调整量 `g_target_pwm_speed_adj`。
*   **动作混合**：
    *   **前腿 (LF, RF)** 伸长：增加对应的舵机 Duty。
    *   **后腿 (LR, RR)** 收缩：减小对应的舵机 Duty。
*   **追重心加速原理**：
    $$\text{目标速度与实际速度偏差} \longrightarrow \text{前腿伸, 后腿收} \longrightarrow \text{车身主动向前倾斜 (Pitch)} \longrightarrow \text{IMU检测到前倾} \longrightarrow \text{直立平衡环驱动轮子向前转以防摔倒} \longrightarrow \text{车辆向前加速}$$
    这种“用腿调姿态，用轮保直立”的机制，极大地提高了车辆在加速和刹车时的响应带宽 and 稳定性。

#### 2) 横滚姿态控制 (Roll Control)
横滚控制分为**被动横滚平衡**与**主动压弯**：

*   **A. 被动横滚平衡 (Passive Roll Balance - 例如单边桥场景)**：
    *   当车身倾斜（例如单侧车轮压上障碍物）时，调用 `Roll_Balance_Control()` 输出调整量 `g_target_pwm_roll_adj`。
    *   采用 **“一边不动，一边缩短”** 的策略：
        *   若左高右低（$adj > 0$）：左侧腿（LF, LR）收缩，右侧腿保持原基准高度，从而吸收路面高度差，保持机身水平。
        *   若右高左低（$adj < 0$）：右侧腿（RF, RR）收缩，左侧腿保持不动。
*   **B. 主动压弯 (Active Banking - 转向侧倾控制)**：
    *   在弯道高速行驶时，为对抗离心力，车辆需主动向弯道内侧侧倾。
    *   系统根据当前转弯角速度计算出目标横滚角，并直接给左右腿前馈不同的高度（`g_target_pwm_turn_roll_*`）。
    *   **极限保护代偿**：当内侧腿由于收缩极限触底无法继续缩短时，系统会自动将**外侧腿伸展量加倍**，以确保目标车身倾角得以实现。

## 3. 电机与舵机 PWM 混控数学模型

在编写底层执行器或修改通道输出时，必须遵循以下混控公式：

### 3.1 足部轮子电机混控公式
最终写入左、右轮电机控制器的 PWM 输出（受最大幅值限制，如限制在 $\pm 8000$ 内）：

$$\begin{aligned}
PWM_{\text{left}} &= gyro\_loop\_out + drive\_ff\_pwm + turn\_gyro\_loop\_out \\
PWM_{\text{right}} &= -gyro\_loop\_out - drive\_ff\_pwm + turn\_gyro\_loop\_out
\end{aligned}$$

> **公式说明**：
> 1. $gyro\_loop\_out$（平衡角速度环输出）与 $drive\_ff\_pwm$（前馈驱动）在左右轮上**符号相反**，用于产生同向的物理推力。
> 2. $turn\_gyro\_loop\_out$（转向角速度环输出）在左右轮上**符号相同**，利用对称安装的物理特性产生反向的物理推力，实现差速转向。

### 3.2 腿部舵机混控公式
每个舵机的目标占空比在 FOC 刷新周期内（如 1ms）按以下步骤计算：

1.  **高度与俯仰基准值**（以左前 LF 舵机为例）：
    $$Duty_{\text{base}, \text{LF}} = \text{SERVO\_MOTOR\_PWM1\_90} + \text{DIR}_{\text{LF}} \cdot g_{\text{target\_pwm\_high}}$$
    其中 $\text{DIR}_x$ 为舵机极性（定义向下伸腿为方向正方向，取值为 $+1$ 或 $-1$）。
2.  **叠加速度调整量**（前后腿差动）：
    $$Duty_{\text{speed}, \text{LF}} = Duty_{\text{base}, \text{LF}} + \text{DIR}_{\text{LF}} \cdot g_{\text{target\_pwm\_speed\_adj}}$$
    *(注：后腿 LR/RR 叠加时为减去该分量，即 $- \text{DIR}_{\text{LR}} \cdot g_{\text{target\_pwm\_speed\_adj}}$)*
3.  **叠加横向调整量**（包含主动压弯与被动平衡）：
    $$Duty_{\text{final}, \text{LF}} = Duty_{\text{speed}, \text{LF}} + \text{DIR}_{\text{LF}} \cdot g_{\text{target\_pwm\_turn\_roll\_lf}} \pm (\text{Roll Balance Adj})$$
4.  **斜率限制滤波（动态平滑）**：
    为防止舵机突变烧毁或引起车身剧烈抖动，最终写入寄存器的值会限制单次循环的步长（加速限幅 $acc\_limit$，减速限幅 $dec\_limit$）：
    $$current\_duty_x = Last\_duty_x + \text{Constrain}(Duty_{\text{final}, x} - Last\_duty_x, -dec\_limit, acc\_limit)$$

## 4. 开发防 Bug 指南

> [!WARNING]
> 以下是在开发和调试过程中最容易踩中的坑，请务必规避：

1.  **切勿使用舵机控制转向**
    如果你的算法（比如 Stanley 寻迹算法）计算出了一个转向控制量，**请将其送入转向角度环中控制轮子差速，绝对不能直接映射或混控到四个舵机上**。腿部舵机不负责偏航转向！
2.  **必须保证舵机软件限幅的有效性**
    在修改 `servo.h` 或更换舵机安装结构后，必须重新测试机械死点，并严格设置 `*_LIMIT_DUTY_MIN` 和 `*_LIMIT_DUTY_MAX`。五连杆并联腿在死点处极易发生机械堵转，数秒内即可烧毁舵机或主板供电芯片。
3.  **注意轮子极性与惯导轴向的匹配**
    由于轮子是差速转向，在修改 IMU 朝向或更换主板时，必须确认 Yaw 角、Pitch 角的方向以及左右电机的正反转极性是否完全匹配，否则会导致系统发散，通电后瞬间飞车或倒地。
4.  **平衡控制永远具有最高优先级**
    在融合轮子 PWM 时，若总输出超出范围（如超过限制 $\pm 8000$），必须进行优先级仲裁，**优先保证自平衡的 PWM（$gyro\_loop\_out$）不被截断**，其次是刹车与转向，最后才是加速前馈。否则，大油门加速或转弯时会导致平衡环失效，车辆直接摔倒。
