# docs/ - 项目文档

## 概述

`docs/` 目录包含项目的设计说明、任务规划、模块文档、调试记录和技能指导。是项目知识沉淀和团队协作的核心文档库。

## 目录结构

```text

├─ 代码统计计时.md                     # 代码量统计

├─ PID_preset_work_log_260712.md       # PID 预设功能开发工作记录
```

## 文档阅读建议

1. **新人入门**：先看 `code文件概览.md` 和 `任务放在哪个核里.md`
2. **了解任务**：查看 `任务规划/` 下对应科目的文档
3. **模块学习**：按需阅读 `模块文档/` 下的具体模块说明
4. **调参参考**：查看 `pid参数.md` 和 `调试/` 下的调试记录
