# GPS+惯导融合改造简报

> 日期：2026-07-01
> 依据：`0701GPS修改.md` 任务书

## 改造目标

废弃纯 GPS 寻迹方案，改用**"基于 Offset 的双频互补滤波架构"**，解决 10Hz GPS 导致的剧烈抽搐和轨迹漂移问题。

## 架构变更

### 旧架构（纯 GPS）
```
GNSS 10Hz → 高斯投影 → gnss_trans.x/y → Pure Pursuit → err_degree
```

### 新架构（GPS+惯导融合）
```
惯导 100Hz ─→ INS 独立积分 ─→ ins_x/y/yaw ─┐
                                              ├─ fuse = ins + offset → Pure Pursuit
GPS 10Hz ──→ 高斯投影 → 杆臂补偿 → ground ──→ 缓慢更新 offset ─┘
              + 延时前馈    + 跃变剔除
              + ZUPT 零速挂起
              + 打滑权重转移
              + THS 航向纠偏
```

## 需实车确认的事项

1. **天线物理参数**：`ANTENNA_HEIGHT_Z`、`ANTENNA_OFFSET_X`、`ANTENNA_OFFSET_Y` 需卷尺测量后修改 `gnss_transform.h`
2. **THS 航向 0 度基准**：打印 `gnss.antenna_direction` 与实际朝向，确认是否需要 90° 偏移校正
3. **杆臂补偿极性**：原地猛推车身，观察 `ground_x/ground_y` 是否反向变化（若是则 Pitch 正负号需反转）
4. **K 值调优**：`K_pos=0.02` 偏惯导信任，若偏离路线调大至 0.05，若抽搐则降至 0.01
5. **GPS 延时**：`GPS_DELAY_SEC=0.12` 为推荐值，高速急刹冲过头时微调
