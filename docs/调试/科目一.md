## 📍 模块一：上位机地图处理 (Python脚本)

**位置：** `tools/webview_nav_marker/`
**作用：** 我们在电脑上用鼠标点的路线是很稀疏的折线，脚本的作用是自动在点与点之间插值，生成几百个点，让小车像老司机一样“丝滑切弯”。

### 🛠️ 造图标准工作流：
1. **打点：** 将小车放在赛道上，利用上位机导出路线文件 `nav_mark_points_xxx.csv`，放到脚本目录下。
2. **格式化：** 运行 `python nav_marker_host.py`。
    * *(如遇点数被截断，可修改脚本中的 `MAX_POINTS_DEFAULT = 500` 为更大的值)*。
3. **插值平滑（核心）：** 运行 `python interpolate.py`。
    * 终端会弹出一个窗口并让你选择 `1~6` 种平滑算法。
    * 👑 **强烈建议输入 `4` (Corner Fillet 倒角算法)**：它会像赛车手一样在弯道提前“切内线”，过弯最快最稳。千万别选 `6` (直线相连)，极易翻车。
    * **进阶微调**：代码中有一个 `INTERPOLATE_DIST = 20.0`，代表每 20mm 生成一个点。嫌小车走得抽搐可以调小（如 `10.0`），但不能太小否则撑爆单片机内存。
4. **生成烧录：** 脚本运行结束后，会自动在 C 代码目录生成 `nav_replay_route_table.h`，重新编译烧录单片机即可。

## 🧠 模块二：导航与路线追踪 (`nav_replay`)

**算法原理：** **纯追踪算法 (Pure Pursuit)**。想象小车是条“狗”，路径前方一定距离有一个虚拟的“兔子”（前瞻点），小车永远在努力朝着这个兔子跑。

### 1. 速度控制参数
| 宏定义名称 | 当前值 | 小白解释 | 调试建议 |
| :--- | :--- | :--- | :--- |
| `NAV_SPEED_FAST` | `-100.0f` | **最高车速**：直道上的飙车速度（负数代表前进）。 | 想提速就改大绝对值，但太快容易冲出赛道。 |
| `NAV_SPEED_SLOW` | `-10.0f` | **最低车速**：过急弯或快到特殊点时的龟速。 | 过弯如果不稳，把这个绝对值调小。 |
| `NAV_DIST_FAR` | `300.0f` | **远距离界限**：离目标大于此距离，全速跑。 | 如果希望小车早点开始减速，把这个值调大。 |

### 2. 转向与过弯参数（决定过弯丝滑度）
* **`PP_LD_MIN_CURVE` (500.0)**：**最小前瞻距离（视野）**。
  * ❌ 值太小：车总想死死贴着线，导致左右疯狂摇摆（画龙）。
  * ❌ 值太大：车看太远，过弯会“抄近道”导致压线或错过特殊点。
* **`PP_LD_SPEED_GAIN` (0.7)**：**速度增益**。车跑得越快，眼睛就要看得越远，这个值决定了随车速放大的倍率。
* **`SPD_CURVE_EXPONENT` (3.5)**：**弯道减速敏感度**。值越大，小车对轻微弯道就不减速（保持动力），只有遇到急弯才猛踩刹车。
* **`FILTER_ALPHA_ANGLE` (0.45)**：**方向盘平滑度**。小车转向一抽一抽的就调小；感觉小车反应迟钝拐不过弯，就调大（最大为1）。

## ⚙️ 模块三：电机与舵机控制 (`pid-new.h`)

**极简 PID 必修课：**
> * **P (比例)**：像“弹簧”，车子偏离目标越多，把它拉回来的力气越大。
> * **D (微分)**：像“减震器”，防止弹簧拉过头，消除来回晃动。

### 1. 维持直立参数（两轮平衡车灵魂）
* **`ANG_KP` (-27.0) 直立刚度**：太小，车软绵绵一推就倒；太大，车会剧烈前后高频抽搐。
* **`ANG_KD` (-10.0) 直立阻尼**：极其重要！配合KP使用。如果没有它，车会像不倒翁一直前后摇。**调大了能消除余震，太大电机会发出噪音。**
* **`ANG_MECH_ZERO` (0.0) 机械零点**：车子的物理重心。如果车静止时老是自己往前跑，稍微改一下这个值（如调成 `-1.5` 或 `1.5`）。

### 2. 速度环参数（让车跑起来）
* **`SPD_KP` (0.0)**：设为多少，车就花多大力气去追目标速度。值太大车容易剧烈点头/仰头。
* **`SPD_MAX_O` (1500.0) 保命限幅**：限制车最多只能倾斜多少度去加速，防止倾角太大直接摔倒扑街。

### 3. 转向与舵机控制
* **`TURN_ANG_KP` (-9.0) 转向灵敏度**：值越大，转向打方向越果断猛烈。
* **`TURN_GYR_KD` (10.0) 转向减震器**：防止方向盘来回抖动发癫。
* **`GYR_DEAD_ZONE` (0.0) 电机死区**：如果低速时电机发出“滋滋”声但轮子不动，增加此值直到刚好能克服摩擦力转动。

## 🎯 实战篇：小白打怪升级调参步骤

**⚠️ 警告：千万不要一上来就去跑全图！每次修改请只动 1 个参数！**

### 🟢 第一阶段：让车站稳（仅限两轮平衡车）
1. 在 `nav_replay.c` 确保目标速度设为 0（让它别跑）。
2. 在 `pid-new.h` 把速度环和角度环清零。
3. **调 `ANG_KP`**：从小到大增加负值（如 -5, -15, -25），直到手扶着车感觉有强抵抗力，松手后车子**高频剧烈抖动**。
4. **调 `ANG_KD`**：从小到大增加负值（如 -2, -5, -10），直到高频抖动刚好消失。推一下车，它能迅速回正且不晃。
5. **调 `ANG_MECH_ZERO`**：修改此值，直到车能安静地原地发呆不乱跑。

### 🟡 第二阶段：稳稳走直道
1. 设定一个较慢的测试速度：`NAV_SPEED_FAST = -30`。
2. 慢慢加大速度环 **`SPD_KP`**。
3. 观察：只要车能平稳往前走就行。如果出现严重的“前后摇摆/点头”，说明 `SPD_KP` 太大了，降下来。

### 🟠 第三阶段：丝滑过弯（最耗时）
这一步主要在 `nav_replay.c` 中调优：
1. **小车像蛇一样左右扭（画龙）？**
   👉 说明前瞻看太近了，把 `PP_LD_MIN_CURVE` 改大（如从 500 改到 600）。
2. **小车老是压线、抄近道错过点位？**
   👉 说明前瞻看太远了，把 `PP_LD_MIN_CURVE` 改小。
3. **急弯车速太快直接飞出赛道？**
   👉 增加 `SPD_CURVE_EXPONENT` (让减速更早触发)，或者把 `NAV_SPEED_SLOW` 绝对值调小。

### 💡 终极建议
* 电池电量会严重影响控制参数（电压低时车会“发软”）。**请务必在电池满电/电量充足的状态下进行调参比赛！**
* 遇到实在过不去的弯，除了调代码，也可以重新跑一遍 Python 脚本，用 `[4] Corner Fillet` 重新优化一下那一段的地图路径。
