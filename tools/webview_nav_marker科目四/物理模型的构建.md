# 科目四点表速度与差速车纯仿真模型

## 1. 结论与模型层次

当前展示的紫色曲线是**纯差速车点表仿真**，不是路线残差拟合曲线。其前向计算只使用：

```text
点表 x/y、target_speed、curvature
初始状态 v_left(0)、v_right(0)、yaw(0)、路线距离 s(0)
离线标定的轮距与左右轮动力学参数
```

每次仿真均同时递推左右轮速度、车体前进速度、偏航角速度、偏航角和路线距离。仿真过程中不读取当前运行的 `vx_body`、`speed_L`、`speed_R`、`relative_yaw`，也不读取路线历史残差表。

模型中还有两个独立的辅助层，不应与紫线混淆：

| 层次 | 是否纯仿真 | 作用 |
|---|---|---|
| 紫色差速车模型 | 是 | 根据点表联立模拟前进与转向 |
| 纵向 ARX 模型 | 是，但为数据驱动低阶模型 | 用于识别车辆响应、比较一步和递推预测 |
| 路线残差修正层 | 否 | 利用同一路线历史数据改善曲线拟合，仅作可选经验校正 |

历史日志只用于离线标定参数和验证模型质量。

## 2. 数据筛选和统一符号

只分析自动回放状态：

```text
g_replay_state == 1
```

当前数据共 5 次运行、6,460 帧，采样周期中位数为 10 ms。

日志方向约定中，前进时 `vx_body`、`target_speed_set` 和右轮原始转速均为负，因此统一使用：

```text
v_body  = -vx_body
u       = -target_speed_set
v_left  = 4.79 * speed_L
v_right = -4.79 * speed_R
v_wheel = (v_left + v_right) / 2
```

单位为：`v_*` 是 mm/s，`u` 是 RPM。`v_body` 是验证速度，`v_left` 和 `v_right` 用于标定差速车轮动力学。

日志没有直接给出点表序号，因此按最近坐标匹配：

```text
route_index[k] = argmin_i || [nav_x[k], nav_y[k]] - [x[i], y[i]] ||
```

本数据中点表序号单调递增，匹配误差中位数约 22.4 mm，95% 分位约 82.5 mm。

## 3. 差速车运动学

差速车的理想运动学关系为：

```text
v        = (v_right + v_left) / 2
omega    = (v_right - v_left) / B
psi[k+1] = psi[k] + omega[k+1] * dt
s[k+1]   = s[k] + v[k+1] * dt
```

其中：

- `B`：等效轮距，单位 mm；
- `omega`：偏航角速度，单位 rad/s；
- `psi`：相对偏航角，单位 rad；
- `s`：沿点表的累计路线距离，单位 mm。

用 `relative_yaw` 展开、求导后的偏航角速度与左右轮速差标定轮距。对异常样本进行筛选后，得到：

```text
B = 241.5 mm
```

实际曲率可由日志计算：

```text
kappa_actual = omega / v_wheel
```

计划曲率与由偏航角/轮速估计的实际曲率相关系数约为 0.874。两者并不完全相同，因此纯仿真可描述整体转向趋势，但不能预测路面摩擦、轮胎打滑、控制饱和和传感器突变造成的所有局部差异。

## 4. 点表输入如何生成左右轮目标速度

点表给出平均目标转速和曲率。先转换平均目标线速度：

```text
u[i]     = -target_speed[i]
v_cmd[i] = 4.79 * u[i]
```

对于当前路线点 `i`，按差速运动学分配左右轮目标速度：

```text
v_left_cmd[i]  = v_cmd[i] * (1 - B * kappa[i] / 2)
v_right_cmd[i] = v_cmd[i] * (1 + B * kappa[i] / 2)
```

正曲率时右轮目标速度大于左轮目标速度；负曲率时相反。这样，点表曲率直接改变左右轮的速度差，转向和前进由同一个状态方程组联立生成。

## 5. 左右轮动力学标定

理想运动学不包含电机、轮胎和速度环的响应滞后，因此为左右轮各拟合一个一阶离散动力学：

```text
v_left[k]  = c_left  + a_left  * v_left[k-1]  + b_left  * v_left_cmd[k]
v_right[k] = c_right + a_right * v_right[k-1] + b_right * v_right_cmd[k]
```

当前数据集的全数据标定参数为：

```text
left wheel:
  c_left = -7.026971
  a_left =  0.986864
  b_left =  0.017043

right wheel:
  c_right = -5.378335
  a_right =  0.985844
  b_right =  0.017506
```

左右轮极点接近 1，等价于约 0.70--0.76 s 的速度响应时间常数。轮模型输出进入第 3 节的差速运动学方程，得到同步的：

```text
predicted_left_speed_mm_s
predicted_right_speed_mm_s
predicted_speed_mm_s
predicted_yaw_rate_rad_s
predicted_yaw_deg
distance_mm
```

## 6. 紫色纯仿真的完整递推过程

仿真初始状态默认设为：

```text
s[0] = 0 mm
v_left[0] = v_right[0] = 0 mm/s
psi[0] = 0 rad
dt = 0.01 s
```

每个 10 ms 周期执行：

```text
1. 由当前 s[k] 在点表累计弧长中查找 route_index i
2. 读取 target_speed[i]、curvature[i]
3. 按第 4 节计算 v_left_cmd[i]、v_right_cmd[i]
4. 按第 5 节递推 v_left[k+1]、v_right[k+1]
5. 计算 v[k+1] = (v_left[k+1] + v_right[k+1]) / 2
6. 计算 omega[k+1] = (v_right[k+1] - v_left[k+1]) / B
7. 更新 psi[k+1] 和 s[k+1]
8. 到达最后一个点表点时结束
```

该仿真输出的紫色速度曲线由上述状态递推产生，不含逐点历史速度修正。进入回放时若小车已经有速度，应给定真实初值 `v_left(0)`、`v_right(0)`，而不应强制设为零。

## 7. 偏航状态模型和纵向 ARX 对照模型

### 7.1 偏航状态模型

作为诊断和交叉验证，额外拟合了计划曲率到实际偏航角速度的一阶模型：

```text
omega[k] = -0.00419
         + 0.88825 * omega[k-1]
         + 0.08360 * v[k-1] * kappa_plan[k]
```

紫色纯仿真不依赖该拟合式，而是直接由左右轮动态和 `omega=(v_right-v_left)/B` 得到偏航角速度。这个额外模型用于检查计划曲率是否被车辆实际执行，以及定位曲线段误差。

### 7.2 纵向 ARX 对照

还测试了静态、一阶和二阶纵向 ARX。无曲率一阶模型为：

```text
v[k] = -8.595 + 0.986629*v[k-1] + 0.084723*u[k]
```

它的等效时间常数约为 0.743 s。二阶 ARX 一步预测最准确，但长时间递推更容易漂移，因此不作为纯点表紫线的主模型。

| 模型 | 一步预测平均 RMSE (mm/s) | 递推平均 RMSE (mm/s) |
|---|---:|---:|
| 静态增益 | 615.4 | 615.4 |
| 一阶 ARX | 28.9 | 162.5 |
| 一阶曲率 ARX | 28.5 | 178.6 |
| 二阶 ARX | 19.8 | 232.8 |

一步预测使用真实的上一帧速度；递推预测使用模型自己的上一帧速度。只有递推形式才与点表-only 预测相同。

## 8. 纯仿真验证与精度边界

对差速车纯仿真进行按文件留一验证：每次用其余 4 次日志标定轮距和左右轮参数，再预测被留出的运行。结果为：

```text
平均 RMSE = 164.7 mm/s
平均 MAE  = 115.4 mm/s
```

纯仿真通常能正确反映加速、减速、弯道前后的整体速度趋势和偏航趋势，但无法预知：

- 瞬时打滑、地面附着变化；
- 左右电机电压、温度和负载变化；
- 转向/循迹控制器对实际轨迹偏差的额外调节；
- 视觉融合或速度测量的尖峰。

因此，当需要未知路线上的可解释速度预测时，应使用紫色纯仿真；当需要已标定同一路线上的最高拟合精度时，可以额外使用下一节的经验残差层，但它不再是纯仿真。

## 9. 可选：路线专用残差修正层（非纯仿真）

以前的“路线校正紫线”并非纯仿真。它的计算为：

```text
e[i] = median( v_wheel[k] - v_base(route_index[k]) )
delta_v_route[i] = median5(e[i])
v_calibrated[i] = max(v_base[i] + delta_v_route[i], 0)
```

其中 `e[i]` 来自当前路线历史日志。该经验层在留一日志验证中可将路线对齐 RMSE 从约 173.5 mm/s 降至约 81.3 mm/s，但它依赖同一条路线的历史残差，不能称为纯物理模型，也不用于当前紫色纯仿真图。

## 11. 建议

1. 对未知路线：使用紫色纯差速车仿真，输入新点表、轮距和轮模型参数。
2. 对当前路线：优先观察紫色纯仿真是否满足速度规划的趋势要求；只在需要更高的路线复现精度时启用非纯残差修正层。
3. 对真实上车：应记录回放开始瞬间的左右轮速度作为初值，以改善前 1 s 的预测。
4. 要提高跨路线精度：需要更多不同曲率、速度、载荷和地面条件的日志，并引入电机 PWM、电池电压、加速度和控制器误差等外部输入。
