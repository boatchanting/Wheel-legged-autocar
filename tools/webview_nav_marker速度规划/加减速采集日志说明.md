# 加减速采集日志怎么读

这个文件夹里每次采集通常有一对文件：

- `accel_brake_*.csv`：逐帧原始日志，用来画曲线、拟合刹车距离。
- `accel_brake_*.json`：单次采集摘要，用来快速判断这次数据是否完整。
- `brake_summary.csv`：所有采集的汇总表。

## 先看 JSON

优先打开对应的 `.json`，看这些字段：

- `status`：`completed` 表示自动完成；`failed` 也不一定完全不能用，要看 CSV 里是否有 `accel` 和 `brake` 两段。
- `target_motion_speed_mm_s`：本次设定的前进速度，单位 mm/s，支持正反向。
- `brake_target_speed_mm_s`：刹车阶段目标速度，正常急停一般是 `0`。
- `accel_time_s`、`brake_time_s`：加速和刹车阶段用时。
- `accel_distance_mm`、`brake_distance_mm`：加速和刹车阶段惯导里程。
- `sample_count`：记录帧数。

做速度-刹车距离拟合时，核心先用 `brake_distance_mm`，再结合 CSV 复核实际刹车起点速度。

## 再看 CSV

CSV 是逐帧数据，一行是一帧。最重要的列：

- `elapsed_s` / `frame_elapsed_ms`：从本次开始采集后的计时。
- `phase`：阶段，常见为 `accel`、`hold`、`brake`。
- `brake_trigger`：刹车触发来源，`auto` 是自动检测触发，`manual` 是上位机手动刹车，`remote_ch5` 是遥控 CH5 触发。
- `vx_body`：惯导解算的车体前向速度，拟合时建议优先用它。
- `target_speed`：车端当前速度目标，是车端内部单位，不是 mm/s。
- `target_motion_speed_mm_s`：本次上位机设定目标速度，单位 mm/s。
- `brake_target_speed_mm_s`：刹车阶段目标速度，单位 mm/s。
- `distance_from_start`：从本次开始后的惯导距离。
- `phase_distance`：当前阶段内的距离，刹车段里就是刹车距离的逐帧增长。
- `pid_mode`：`0` 普通 PID，`1` 加速 PID，`2` 刹车 PID。

## 拟合刹车距离建议

1. 筛选 `phase == brake` 的行。
2. 取刹车段第一行附近的 `vx_body` 作为实际开始刹车速度。
3. 取刹车段最后一行的 `phase_distance`，或 JSON 里的 `brake_distance_mm`，作为刹车距离。
4. 按多组数据整理成 `开始刹车速度 mm/s -> 刹车距离 mm`。
5. 拟合时可以先试二次关系：`distance = a * speed^2 + b * speed + c`。

## 姿态和 IMU 字段

这些字段用于检查刹车时车身是否异常：

- `att_roll`、`att_pitch`、`att_yaw`：姿态角。
- `imu_gyro_x`、`imu_gyro_y`、`imu_gyro_z`：陀螺仪处理后用于姿态/控制的数据。
- `imu_acc_x`、`imu_acc_y`、`imu_acc_z`：加速度计数据。
- `imu_grav_x`、`imu_grav_y`、`imu_grav_z`：重力分量。

如果刹车时转弯，重点看 `att_yaw`、`imu_gyro_z` 是否有持续单方向变化。

## 转向和 PWM 诊断字段

新固件烧录后，新日志会增加这些字段：

- `err_degree`：转向角度误差。
- `turn_angle_loop_out`：转向角度环输出。
- `turn_gyro_loop_out`：转向角速度环输出，也就是转向 PWM 分量。
- `final_pwm_left`、`final_pwm_right`：最终输出给左右电机的 PWM。
- `has_control_debug`：是否收到了控制诊断帧。
- `control_debug_age_ms`：诊断帧和当前主日志帧的时间差。

刹车右转时，如果 `turn_gyro_loop_out` 不是 0，说明转向控制还在给命令；如果 `turn_gyro_loop_out` 是 0 但 `final_pwm_left/right` 明显不对称，则继续查平衡环、刹车前馈或机械左右差异。

## CH5 说明

采集中按 CH5 会被记录为一次刹车触发：

- `phase` 会进入 `brake`。
- `brake_trigger` 会写 `remote_ch5`。
- 刹车目标会改为 `0 mm/s`。
- 如果启用多预设 PID，刹车阶段会用 `pid_mode = 2`。

CH6 关电机、倒地、反向刹车仍然按安全退出处理，不会当作正常刹车数据。
