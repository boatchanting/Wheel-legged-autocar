1) 任务定义

输入

车载 AVI（DIB）视频，通常分辨率 96x60 或 94x60；通过帧提取脚本转为 frame_*.png 序列。

输出

叠加可视化视频（overlay AVI）+ 逐帧时序 JSON + 文本摘要。 输出里包含 detected、score、bbox、entry_bottom_y。

判定目标

在单边桥阶段，识别“白色 PVC 区域是否进入可见范围”，为状态机切换与入口距离估计提供视觉证据。

2) 总体流程

3) 固定阈值算法（detect_white_pvc_video.py）

固定参数

参数默认值用途
WHITE_THRESHOLD245灰度二值化阈值，生成白色掩码
MIN_AREA120连通域最小面积
MIN_WIDTH12连通域最小宽度
MIN_HEIGHT4连通域最小高度
MIN_FILL_RATIO0.25区域紧凑度下限
MIN_DECISION_SCORE0.58最终判定阈值

判定逻辑

1) 先按 gray >= 245 得到候选白色像素。

2) 做 4 邻域连通域，计算每个区域的几何与亮度特征。

3) 先硬过滤（面积、宽高、填充率、是否贴边），再做打分。

4) 取最高分区域，且 score >= 0.58 才判定 PVC。

score = 0.35 * area_score + 0.18 * width_score + 0.12 * height_score + 0.12 * fill_score + 0.18 * border_score + 0.05 * brightness_score

其中 border_score 是强先验：PVC 入口通常从图像边缘进入，所以“贴边”特征权重较高。

自适应模式与固定模式关系

自适应版本复用了固定模式的连通域提取、硬过滤和评分公式，仅替换“每帧白色阈值”的计算方式； 这样可以减少整体亮度变化时的漏检/误检，同时保持原有结构特征逻辑不变。

4) 自适应阈值算法（detect_white_pvc_video_adaptive.py）

每帧阈值估计

tail_candidate = P97 + 0.55 * max(0, P99.5 - P97) sigma_candidate = mean + 2.10 * std candidate = clamp(max(tail_candidate, sigma_candidate), min_threshold, max_threshold)

含义：同时看“亮度尾部结构”和“全局亮度波动”，防止阈值被单一指标拉偏。

时间平滑

if t == 0: threshold_t = candidate_t else: threshold_t = clamp(alpha * threshold_(t-1) + (1 - alpha) * candidate_t, min, max)

默认 alpha = 0.82，可抑制“颠簸或曝光突变”造成的阈值抖动。

默认参数

参数默认值作用
min-threshold235.0阈值下限，抑制暗场误检
max-threshold252.0阈值上限，避免过度收紧
smooth-alpha0.82阈值时间平滑强度
initial-thresholdnull首帧阈值种子（可选）

输出新增字段

相比固定阈值版本，自适应 JSON 额外输出：

{
  "threshold": 247.183,
  "threshold_candidate": 248.376
}

便于定位“误检/漏检发生时，阈值是否异常波动”。

5) 控制侧接入建议

建议 1：连续帧确认

不建议单帧触发。控制逻辑中可使用“连续 3~5 帧 detected=true”作为进入入口搜索区的确认条件。

建议 2：距离估计

使用 entry_bottom_y 查表映射前向距离。通常 y 越大，目标越近。

建议 3：横向微调

用 bbox 或 centroid_x 与图像中心的偏差，作为小幅转向修正，不直接大幅覆盖主控航向。

建议 4：失配兜底

若连续多帧无 PVC，可退回“里程+航向”保守模式，等待下一次稳定视觉确认。

6) 调参建议（按现象定位）

现象优先调整原因
暗场误检增多 提高 min-threshold（如 235→238） 压制低灰度背景被归入白色掩码
PVC 漏检较多 降低 min-threshold 或降低 MIN_DECISION_SCORE 阈值或评分门槛过高
阈值跳变导致抖动 提高 smooth-alpha（如 0.82→0.88） 增加时间平滑，减少瞬态波动
高亮小反光误检 提高 MIN_AREA、MIN_WIDTH 加强几何约束，过滤小亮斑
中央亮斑被误判 保持或加强 touches_border 约束 PVC 入口一般从边缘进入，贴边先验有效
